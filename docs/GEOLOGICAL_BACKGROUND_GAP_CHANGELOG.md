# 消除地质背景与底部年代条之间的白缝（2026-11-03）

## 原因与修复

Dating 和云树均把底部年代条放在绘图区末端之后，历史背景矩形只画到绘图区末端，留下固定空白。`render/time-background.js` 现将背景填色延伸到底部年代条的上沿。共用方法的参数和调用端不变；保留 `plotBottom` 端口兼容，填色终点改用已传入的 `bottomPeriodY`。

只修改背景矩形高度。树枝、样品、文字、地质色块和边框、时间轴及整图尺寸不移动；原树、年龄、HPD、冲突统计和科学缓存键不变。两种工作区继续复用同一实现，未增加用户参数或第二套绘制规则。
