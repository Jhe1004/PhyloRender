# 83阶段：时间树与地质背景模块化

基线为82阶段已验收的macOS arm64源码。历史82/80、原始输入、共享本机服务和公网均未修改。

## 实施范围

- 新增core/time-display：单位换算、时间范围文字与判断、独立字号计算、只读地质配色表。
- 新增render/time-background：明确SVG工厂、量字、刻度端口；Dating和云树继续共用同一背景与时间轴实现。
- 新增render/time-tree：时间枝、HPD与点估计标记、末端标签、时间节点标签的协作排版。
- app保留导入、年龄模型验证、样式快照、原子事务和中文工作台反馈；渲染器不拿整份state或控件查询器。
- 主文件8,418行降为7,946行；体量门禁从8,420收紧为7,950行。新模块登记加载、构建及静态/镜像目录覆盖，未构建镜像。
- 迁移旧源代码截取/位置断言至所属模块，保留字号、几何与显示断言；新增直接接口、跨文档隔离、常量只读和取消反例。
- 新旧精确图件对照扩至7组：四工作区及Dating单位换算/范围、大字号、未确认单位。只排除SVG metadata，所有字体、文字、属性、顺序、坐标和完整分辨率PNG都比较。

## 保持不变

科学年龄模型、树拓扑/枝长/支持率/HPD、原生参数、统计分母、默认值、候选顺序与24ms协作预算均未更换。

## 当前Dating支持率显示边界

- Dating图不显示主树或附加树中的posterior、bootstrap等支持率。
- 满支持率不会加粗分支，也不会生成支持率圆点、星号或数字。
- 节点年龄、95% HPD和可选的其他节点数字继续显示；普通树、云树和双树冲突图保持各自原有规则。
- Dating工作台隐藏支持率上传与显示规则；MCP的`workspace: "time"`拒绝`support_trees`。
原始树仍在适配层复制后用于派生坐标；显示单位换算不改原始年龄。
地质配色范围与数值沿用基线，不因本轮冻结表而更新科学年代界线。

## 验收与限制

正式完成须以同阶段02_验证记录/verification.json、最终命令退出码与构建指纹为准，不以本文件存在为准。

本轮不包含Linux/Windows验收、共享服务重启、GitHub推送、公网部署、镜像构建或许可证批准。
