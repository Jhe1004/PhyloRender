## 工程验证执行约束

1. 固定输入、任务、成功条件、资源上限和失败处理。四工作区分别覆盖导入、显示编辑、失败恢复及可复现导出。
2. 每次运行记录输入散列、构建与依赖版本、参数、实际退出码、错误、重试、输出散列和科学不变量。失败运行保留。
3. 重绘一致性用于验证可复现性；统计定义仍需独立反例或方法对照，不能用同核心重算替代独立科学验证。
4. 脚本耗时只描述指定环境中的工程运行，不作为易用性或模型能力的比较结果。

默认输出 SVG。论文中的 PNG、预览及拆分面板必须明确请求并检查真实文件；不得用预览截图证明原始数据或算法正确。真实私有测试树不自动进入公开附录。
