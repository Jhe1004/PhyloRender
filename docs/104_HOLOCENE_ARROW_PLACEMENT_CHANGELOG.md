# 104阶段：Holocene长箭头与其余简称原位

本阶段从103号已验收源码建立独立副本。用户确认只有Holocene需要外置全称；其他年代即使简称略微压到边框，也应留在原色块内，不能用箭头移到旁边。

## 用户可见规则

- Holocene色块过窄时，块内不显示`H`。从真实色块中心绘制一条明显较长、线宽更清楚的矢量箭头，箭头末端旁只显示完整英文`Holocene`。
- 其他年代继续按宽度选择英文全称或既有简称。无论简称是否完全落在边框内，都保留在色块中心，不增加箭头或外置名称。
- 普通缩写仍在旁边给出`缩写 = 全称`说明；Holocene的外置全称本身就是说明，因此不再显示`H = Holocene`。
- Dating树和基因树—物种树冲突图继续共用`render/time-background.js`，网页和MCP没有第二套规则。

## 不变量与验收

年代边界、色块宽度和颜色、树坐标、年龄、HPD、拓扑、样品名称及统计不变。直接反例必须证明103号会外置多个简称且Holocene箭头横向长度不足；修复后只能存在一个Holocene外置标注和一条箭头，箭头横向长度至少32个绘图单位。Dating与云树浏览器／MCP专项必须检查同一规则；限定图件对照只允许共用地质年代文字和箭头发生本轮明确变化，其他图层与年代色块几何保持一致。
