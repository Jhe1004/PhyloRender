# 88：四项实测缺陷修复

基线为86号已验收源码；87号仅作为功能QA证据，不是新源码基线。用户明确授权完整修复F01–F04。原始测试树、历史代码、共享本机服务、公网服务、许可证决定均不在本轮改动范围。

## F01 配置行距与字号

figure-contract新增无损行距序列化函数。手动字号编辑保留实际行距；比例在0.9–4 em内时仍使用em，越界则导出精确绝对像素。绝对像素范围共用GUI已有的4.5–72 px（18 px的25–400%），接受小数；不再使用桥接/schema旧的17–64整数范围。不会通过钳制比例改变树图。

严格网页/MCP属性比较另检出跨工作区复用MCP页面时会残留旧云树/双树诊断属性。共用协作渲染入口在绘制前清除本渲染器拥有的旧模式诊断，而不删除图形属性或科学数据。验收保留全部data-*属性；不能通过忽略诊断字段假装一致。

## F02 双树标题连续输入

标题input事件改用已有非模态settings协作渲染队列。完整导入、分组计算等事务仍用原有有界runTreeLoad。真实键盘输入须覆盖两个标题及0/30/100 ms字符间隔，检查焦点、最后完整文本、SVG标题和原始树；样式编辑不能重新运行科学引擎。

## F03 软件生成的分组图例

自动分组名称由“核树分支N”改为“Primary-tree clade N”。只改软件生成的文字；用户明确输入的中文或其他名称不翻译。成员、颜色归属、拓扑及数值不变。旧版自动中文图例相关的SVG/PNG应有预期差异，不能忽略全部文本伪造新旧一致。

## F04 MCMCtree HPD兼容及验证

共享注释扫描允许数字开头的key，同时保留原始条目。时间模型识别height_95%_HPD、height_95_HPD、height_HPD、95%HPD、95%_HPD（归一化后大小写不敏感）。区间必须恰含两个有限非负从小到大排列的端点；反向、非有限、少/多端点、相互冲突的重复或别名均拒绝。相同别名计一次。原文与点年龄不变，不使用区间中点替代节点年龄。

单树配置在切工作区、重置控件或替换原文前完成科学预检；HPD拒绝后上一有效图仍可导出。移除app中会静默排序端点的旧适配函数，GUI/MCP均走共享模型。

## 验证与边界

新增tests/acceptance-defects.test.cjs与mcp-server/tests/acceptance-defects.mjs，后者纳入--integration门禁。详细命令、退出码、真实图件、31文件输入hash、真实13,797棵基因树压力结果、构建ID以本阶段02_验证记录/verification.json和03_交付报告为准。文档存在不等于测试通过。

本轮不是通用分子定年接口改造，不支持异时末端，不对所有软件版本作未经测试的兼容声明；未部署、推送、重启共享服务或批准发行许可。

补充旧/新图件比较保留了一个未解边界：21组SVG除构建metadata外精确一致；其中20组完整PNG字节一致，cloud-gene-only的PNG有342/11,123,072像素的轻微颜色差异（最大通道差2/255）。同一份保存SVG在同一及不同私有浏览器的重复栅格化均一致，故不能直接归因于浏览器或编码，不宣称21组PNG门禁全过。原门禁和失败日志未修改、未删除，也未引入像素容差。这不改变四项缺陷的专项/完整功能回归通过结论，但今后的行为等价重构仍需处理此严格PNG边界。
