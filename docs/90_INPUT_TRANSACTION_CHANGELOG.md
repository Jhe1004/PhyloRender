# 90阶段：解析身份与整套配置事务修复

基线为88号源码；89号只有检查证据，未用作开发基线。本轮只关闭E01、E02、E03及配套E04，不改统计方法、布局评分、许可状态或服务部署。

## 用户可见变化

- E01：`(Homo sapiens:1,B:1);` 明确拒绝，要求写成 `('Homo sapiens':1,B:1);`。不能把名称截成第二个词。合法引号、内部节点标签和数字保持原语义。
- E02：Nexus用引号/注释感知的语句扫描，TREE与TRANSLATE都只取所属TREES BLOCK。注释里的假映射、其他块的文字不能改样品名称。重复表、重复编号/名称、不完整条目、未闭合注释/引号/块明确拒绝。多树仍要求显式选择/汇总。
- E03：网页配置上传和MCP桥接loadFigure以一次完整事务处理；内部树导入加入同一个所有者。后续数据、分组、第二棵树、时间检查、字体/排版或图件生成失败，恢复原模型、原文、控件、分组、人工标注、桥接辅助缓存和画布。取消/超时走同一恢复路径；正在操作时拒绝外部导出和第二份配置。
- E04：通用消息从普通树导入卡片移至工作台公共区域，四个模式的当前标签页均能看到。错误用可访问的alert角色；修正文件后可在原页面重试。

## 模块与边界

`core/tree-input.js`是唯一科学解析器。新增`core/figure-input-validation.js`只做只读结构验证；新增`ui/import-state.js`通过限定端口保存/恢复模型和具体控件，不读取全局state/DOM。app协调任务，桥接映射语义；不存在另一份MCP解析或绘图算法。两个模块已登记架构清单；app/bridge体量上限未提高。

本轮采用完整操作快照加失败恢复，不声称所有历史字段已类型化或改成离线候选文档。恢复重绘失败会返回`FIGURE_ROLLBACK_FAILED`，不会吞掉异常。合法图件几何应与88号保持一致，需执行原严格SVG/PNG对照。
