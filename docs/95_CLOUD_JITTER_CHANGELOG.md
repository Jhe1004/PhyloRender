# 95阶段：可复现的云层抖动参数

从94号已验收源码继续开发。只增加云线显示扰动；不修改时间、拓扑、枝长、支持率、统计、物种树布局、共有节点锚点、分组颜色或默认透明度。历史阶段只读。

## 操作与语义

位置：树形 → 基因树云层 → 云层抖动强度。整数0–100，默认0。0使用原来的直线，调大后基因枝线中段纵向散开更明显。百分比表示显示强度，不是进化不确定性、时间误差、置信区间或冲突比例。

基因枝线两端完全不动，包括末端样品、根和共有内部节点。物种树与饼图不抖动。零时间跨度的枝线保持直线；不能通过抖动制造时间跨度。关闭云层时参数保留，但没有显示效果。

MCP和配置字段为options.cloud.jitter。共享figure-contract定义默认值、整数范围和最大幅度，schema与桥接共同验证；负数、超范围、小数、字符串和null明确拒绝。有效配置可保存、重导入并由MCP复现；旧配置不含该字段时仍为0。

## 模块和几何契约

core/cloud-jitter只接受已验证科学树、年龄与行坐标、横坐标函数和本次显示参数，返回新的子节点→SVG路径Map。没有DOM、文件、随机数发生器、全局缓存、原生计算或科学写入。年龄与行映射先复制；节点/枝线逐个yield，取消不返回半成品。render/cloud-tree在93号共有行对齐之后调用它；render/cloud-branches通过显式路径Map绘制，主树不传这个Map。

路径使用三次曲线。横向两个控制点分别在原时间区间的三分之一和三分之二处，因此横向时间参数仍线性。纵向两个控制点在原直线位置加同一偏移；端点保留原精确坐标。实际中点偏离量至多是样品行距的一半，按强度线性缩放；到达绘图区边缘时缩减幅度。控制点留在绘图区内，不越过时间轴或进入名称区。

扰动由固定cloud-jitter-v1算法决定，使用原始样品名称、子树结构和基因树输入序号。重复输入的树可以有不同扰动；显示名、临时节点ID和姊妹群顺序不参与种子。相同原始数据、基因树输入顺序、坐标和参数重画一致。更换行距或排列会改变显示坐标，但不改变科学输入。

默认0不新增SVG属性、不改变现有图件文字或图层。jitter不加入analysis-spec科学缓存身份；样式调整不能重启treePL或PhyParts。网页与MCP使用同一个模块，不能另外创建随机抖动实现。
