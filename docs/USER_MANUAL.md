# PhyloRender User Manual & Configurable Options Reference

[← Back to Repository Home](../README.md) · **English** | [简体中文](USER_MANUAL.zh-CN.md) · [Quick Walkthrough](USER_GUIDE.md) · [Algorithms & Architecture](ALGORITHMS_AND_ARCHITECTURE.md)

This manual explains how to prepare publication-ready phylogenetic figures in **PhyloRender**, what options can be adjusted in each of the four workspaces, and how every setting maps across the interactive **Web Workbench**, the **Model Context Protocol (MCP) server**, and natural-language requests guided by the **Agent Skill** (`phylorender-mcp`). Underlying mathematical formulations and runtime consistency architecture are documented in [ALGORITHMS_AND_ARCHITECTURE.md](ALGORITHMS_AND_ARCHITECTURE.md).

## 1. Quick-Start Overview: Choosing a Workspace, Interface, and Coordinate Unit

### Selecting the right workspace for your evolutionary question
PhyloRender provides four dedicated workspaces in the top navigation bar of the Web Workbench (corresponding to the top-level `workspace` field in MCP figure specifications). Each workspace exposes the controls valid for that figure type and blocks inapplicable controls so chronological or topological data cannot be altered by mistake (Table 1).

**Table 1.** Overview of the four PhyloRender workspaces, input requirements, rooting behavior, and intentionally blocked controls.

| Workspace (`workspace`) | Primary Use Case | Required & Optional Tree Inputs | Rooting Policy | Output Width Cap & Supported Exports | Intentionally Blocked Controls (Data Safeguards) |
| --- | --- | --- | --- | --- | --- |
| **Phylogram** (`"phylogeny"`) | Standard ML, Bayesian, or coalescent trees; combining supports across methods (e.g., ML bootstrap + ASTRAL LPP, Zhang et al., 2018). | 1 primary Newick/Nexus tree (`main_tree`, up to 1,500 tips); optional up to 20 support trees (`support_trees`) and 20 node-metric trees (`other_data_trees`). | User-selected outgroup (`rooting.outgroup`), auto-root on unique `Euptelea pleiosperma` if omitted, or `outgroup: null` to keep input root. | Up to `400 mm`; `SVG`, `PNG`, two-panel `Panels`, `.json` spec. | Time axes, HPD bars, cloud layers, and two-tree connectors are hidden. |
| **Time Tree** (`"time"`) | Fossil-calibrated chronograms with divergence ages, 95% HPD credible bars, and ICS geologic bands (Cohen et al., 2013). | 1 dated summary chronogram (`main_tree`, e.g., BEAST MCC, StarBEAST3, or MCMCtree output; up to 1,500 tips); optional `other_data_trees`. | Input root and ages preserved strictly; rerooting disabled. | Up to `400 mm`; `SVG`, `PNG`, two-panel `Panels`, `.json` spec. | Outgroup rerooting, branch-support labels, support dots, full-support branch thickening, and `support_trees` are blocked so ages and HPD bars stay unambiguous. |
| **Tanglegram** (`"conflict"`) | Side-by-side topological comparison (e.g., nuclear vs. plastid/mitochondrial trees, or ML vs. coalescent topologies). | 1 left primary tree (`main_tree`) + 1 right comparison tree (`comparison_tree`, up to 1,500 tips); optional group palette (`sample_groups`). | Web preserves input roots and rotates right tree; MCP also supports `rooting.outgroup` to sync-root both trees on a shared outgroup side. | Up to `800 mm` (double-wide); `SVG`, `PNG`, `.json` spec. | Horizontal branch stretching, right-margin clade bracket bars, and two-panel splitting are disabled (MCP `clades[]` map to group colors without bars). |
| **Cloudogram & Discordance** (`"cloud"`) | Dated species tree overlaid with multi-locus ML gene trees and 2-part or 4-part conflict pies (following Smith et al., 2015). | 1 species tree (`main_tree`) + 1 multi-tree gene-tree file (`gene_trees`, up to 20,000 trees; complete-taxon ML subset up to 30,000 nodes scaled via built-in L-BFGS aligner following Sanderson, 2002; Smith & O'Meara, 2012). | Species-tree root preserved; gene trees rooted by species-tree outgroup (`phyparts_outgroups`) or kept pre-rooted (`"input"`). | Up to `400 mm`; `SVG`, `PNG`, `.json` spec; node discordance TSV table. | Species-tree rerooting, numeric support strings, and two-panel splitting are disabled (horizontal stretching is hidden in Web UI, available in MCP). |

### How the Web Workbench, MCP Server, and Agent Skill work together
In the **Web Workbench**, controls are organized into up to seven left-hand settings tabs (**Data**, **Layout**, **Tip Labels**, **Annotations**, **Time Scale** in *Time Tree*/*Cloudogram*, **Clades** outside *Tanglegram*, and **Export**), where all bounded numeric settings use compact `− / number / ＋` steppers without sliders, paired with a bottom **Optimize Node Label Placement** button and direct canvas interactions (clicking branches to define clades, double-clicking tip names to rename display labels, dragging node labels, right-clicking branches to reroot in *Phylogram*, or right-clicking left-tree nodes to swap sister clades in *Tanglegram*). In the **MCP server**, AI assistants create and revise the exact same figure state through 15 structured tools (`create_figure`, `edit_figure`, `export_figure`, etc.). When the companion **Agent Skill** is active in an MCP client, users state requests in plain language (for example, *"Root on Dipteronia, merge ASTRAL supports onto the ML tree, and add solid tribe brackets inside dashed subfamily brackets"*), and the assistant translates them into validated MCP calls.

### Understanding PhyloRender's coordinate and print units
Every PhyloRender figure is laid out on a canonical canvas width of **`1,000` drawing units (`u`)**, projected linearly from a `1,511-px` internal reference canvas (`1 px ≈ 0.6618 u`). Canonical typography, stroke, and marker dimensions use `*_u` fields (for legacy compatibility, `*_pt` fields convert at **`1 pt = 4000 / 4533 u ≈ 0.8824 u`**, and legacy pixel fields convert at `1 px ≈ 0.6618 u`). Physical print width (`options.output.width_mm`, where `0` selects the workspace maximum of `400 mm` or `800 mm`) and raster density (`options.output.dpi`, `72–1200 DPI`, default `300 DPI` in both Web and MCP) scale only the exported physical width or pixel count. Increasing DPI sharpens PNG exports for journal submission without shrinking fonts or shifting label placements.

## 3. Per-Workspace Reference Guide

### 3.1 Phylogram (`workspace: "phylogeny"`)
The **Phylogram** workspace renders rooted or unrooted maximum-likelihood, Bayesian, and coalescent trees and merges branch support or node metrics from companion analyses onto the primary topology via unrooted bipartition matching ([Algorithms & Architecture Reference](ALGORITHMS_AND_ARCHITECTURE.md), Section S1.1). Users can reroot the primary tree either by selecting a single outgroup taxon in `Layout` and clicking **Reroot by Selected Outgroup**, or by right-clicking any internal branch on the canvas to reroot on a multi-taxon outgroup clade.

### 3.2 Time Tree (`workspace: "time"`)
The **Time Tree** workspace renders fossil-calibrated summary chronograms (such as BEAST TreeAnnotator MCC trees, StarBEAST3 species chronograms, MCMCtree outputs, or `treePL` dated trees). In the Web Workbench, importing a chronogram uses the **Import Time Tree** panel under `Data`: **Step 1** loads the dated tree file, and **Step 2** stays open automatically so you can confirm the input file's time unit (`yr`, `kyr`, or `Mya`) and choose a single uniform node-age statistic across the entire tree. Non-ultrametric trees with tip ages exceeding numerical roundoff tolerance (heterochronous tip-dated trees or sampled ancestors) are rejected clearly rather than zeroed out silently. Branch-support values and rerooting are intentionally blocked so node bars and numbers communicate divergence time and credible intervals exclusively.

### Five domain confirmation gates in the companion Agent Skill
When you work with an AI assistant loaded with the `phylorender-mcp` skill, the assistant follows five strict confirmation rules so it never guesses biological parameters or overrides tuned defaults silently:

1. **Outgroup confirmation gate:** Before creating a *Phylogram*, *Tanglegram* (using the left primary tree's outgroup), or *Cloudogram* (passed as `options.cloud.phyparts_outgroups` to root gene trees while preserving the species-tree root), if you have not specified the outgroup, the assistant inspects the tree and asks you to confirm the outgroup taxon or clade rather than guessing from file order. In *Time Tree*, it preserves your dated root and never asks to reroot.
2. **Sample-mismatch confirmation gate:** Before creating a *Tanglegram*, the assistant runs `compare_tree_samples`. If tip sets differ, it shows the complete `primary_only` and `comparison_only` lists and waits for you to choose `intersection` or `union` (or source-name correction on equal-count spelling mismatches).
3. **Dense chronogram label gate:** If `inspect_tree` reports `160` or more candidate internal-node age labels on a *Time Tree* and you have not set an age window, the assistant asks whether to use the clean default (labeling the older `50%` of the root-to-present span while retaining all 95% HPD bars), label all nodes (`age_minimum: 0`, under a cancellable `1,800 s` render deadline), or apply a custom age range.
4. **Default-first output and override confirmation gate:** New figures always start from PhyloRender's tuned publication defaults (Arial typography, automatic portrait spacing, `1.25×` median tip-width cap, and automatic collision-free label placement). Even if a prompt asks broadly to "beautify" a figure, the assistant will not send non-default font sizes, manual spacing, line weights, aspect ratios, or DPI overrides without first listing the exact proposed parameter values and receiving your confirmation.
5. **Local-first privacy and fast vector-SVG gate:** Ordinary creation and revision steps return vector SVG directly without slow intermediate PNG rasterization (generating PNGs or calling `delete_figure` only when explicitly requested), and local loopback calls (`127.0.0.1:8766`) never fall back to a remote endpoint upon HTTP `429` (`SERVICE_BUSY`) or validation errors, keeping unpublished tree data on your machine.

## 5. Step-by-Step Operational Workflows and Practical Examples

### Workflow 1: Interactive figure preparation in the Web Workbench
1. **Select the workspace:** Open the Web Workbench in your browser and click **Phylogram**, **Time Tree**, **Cloudogram & Discordance**, or **Tanglegram** in the top bar.
2. **Import and validate tree data (`Data` tab):** Upload your primary Newick or Nexus tree. Depending on the workspace, attach companion support trees (*Phylogram*), confirm the file time unit and node-age source in Step 2 (*Time Tree*), choose `intersection` or `union` if tip sets differ (*Tanglegram*), or upload your ML gene-tree collection and list multi-taxon species-tree outgroups (*Cloudogram*).
3. **Root, order, and style tip names (`Layout` & `Tip Labels` tabs):** In *Phylogram*, select an outgroup taxon and click **Reroot by Selected Outgroup** (or right-click an outgroup clade's branch on the canvas and click **Reroot at this branch**). Confirm automatic Latin binomial italics under `Tip Labels`, and optionally double-click individual tips or upload a two-column CSV/TSV/TXT/`.xlsx` table (`original_name, display_name`) to format publication labels.
4. **Add single-tier or nested clade brackets (`Clades` tab):** Click **Select Clade or Taxon**, then click any internal node or branch on the SVG canvas to open the clade dialog. Enter the taxon group name, pick a color swatch, and leave `Bracket tier` on `Automatic` (inner solid tier for tribes, outer dashed tier for enclosing subfamilies) or choose `Inner tier 1` through `Outer tier 6`. Use the top canvas toolbar (`Fit window`, `Fit width`, `Alt + scroll` zoom, and `Find taxon...`) to navigate large trees.
5. **Optimize node annotations and export (`Annotations`, `Time Scale` & `Export` tabs):** Fine-tune support masking, HPD bar scope, discordance pie mode, or ICS timescale font sizes via the `− / +` steppers. Click **Optimize Node Label Placement** at the bottom of the workbench to recompute zero-overlap label slots and leader lines across the figure (individual node labels can also be dragged on the canvas). Open `Export` to set DPI (`72–1200`, default `300`) and download an editable **SVG**, **PNG**, **Export Two-Panel Split** `.zip` bundle, or `.json` figure specification.

### Workflow 2: Conversational plotting and revision rollback with an AI Agent
With the MCP server connected and the `phylorender-mcp` skill active in your AI client, provide your tree file paths and biological context in plain language. Including the outgroup (or time unit) upfront allows the agent to generate the figure in a single pass:

> **Example initial prompt (*Phylogram* with dual supports):**
> *"Using `sapindaceae_ml.treefile` as the primary ML tree (bootstrap percentages) and `sapindaceae_astral.tre` as an auxiliary support tree (ASTRAL posterior probabilities, 0–1), create a Phylogram rooted on `Acer_truncatum` and `Dipteronia_sinensis` using standard publication defaults and export an SVG."*

> **Example follow-up revision prompt (semantic editing on the committed revision):**
> *"Add inner solid brackets (tier 0) for tribes Nephelieae (MRCA of `Dimocarpus_longan` and `Litchi_chinensis`, `#2b6f6b`) and Sapindeae (MRCA of `Sapindus_mukorossi` and `Koelreuteria_paniculata`, `#b85d3b`), enclosed by an outer dashed bracket (tier 1) for subfamily Sapindoideae (`#1f2937`)."*

Behind the scenes, the agent hydrates local tree files, calls `inspect_tree` $\rightarrow$ `create_figure` (`revision: 1`) $\rightarrow$ `inspect_figure` $\rightarrow$ `edit_figure` (`base_revision: 1` $\rightarrow$ `revision: 2`), and verifies `topology_unchanged: true` and `remaining_collisions: 0` in the returned report. If you want to undo a later styling experiment, say *"Roll back the figure to revision 1"*, and the agent invokes `restore_revision` without erasing intermediate history.

### Workflow 3: Bidirectional handoff between the Browser Workbench and AI Agents
1. **Agent $\rightarrow$ Browser (interactive visual touch-up):** Ask the AI agent to batch-build all MRCA clade brackets and multi-tree pairings from your classification table and save a complete portable `.json` figure specification (embedding the local raw tree strings into `main_tree.content` and companion `content` fields alongside the normalized `options` and `clades` from `inspect_figure` / `get_figure_spec`). Open the Web Workbench, go to `Export` $\rightarrow$ **Load Figure Spec (.json)**, inspect the live SVG canvas interactively, drag any individual leader label if desired, and click **Export SVG**.
2. **Browser $\rightarrow$ Agent (manuscript-wide style standardization):** Design and polish your main phylogeny interactively in the Web Workbench until typography, stroke weights, and subfamily/tribe color swatches match your target journal's style. Click **Export Figure Spec (.json)** and hand that JSON file to your AI agent: *"Apply the exact typography, stroke weights, and clade color palette from `fig3a_spec.json` (confirming those exact overrides) to our StarBEAST3 chronogram (`fig3b.trees`, ages in Mya) and our 86-gene cloudogram, then export SVG and 600-DPI PNG files for all figures."*
