# 82阶段：模块化与状态隔离

基线为80阶段已验收的macOS arm64开发副本。本轮没有覆盖历史目录、推送GitHub、部署软件或重启共享MCP。

## 实施

- 从主文件提取7个共用模块：样品身份、学名样式、树几何、标签几何、文档状态、协作调度及节点标签渲染。
- app保留短兼容委托和明确端口，网页和MCP加载同一模块。
- 文档根字段集中声明并seal；新文档不共享集合；完整快照校验后恢复，派生布局不入快照。
- 架构清单及自动门禁纳入check-project；限制主文件增长、隐藏DOM/状态/IO依赖及漏加载/漏打包。
- 更新构建清单、受限静态路由和Docker COPY。没有构建或发布Docker镜像，原生组件许可边界不变。
- 迁移直接从app截取实现的测试到模块接口，保留原几何、字号、身份及科学断言。
- 增加模块契约、边界反例、文档独立性、生成器取消和真实旧/新图件等价测试。

## 保留的行为

科学算法、输入验证规则、拓扑、支持率、年龄、HPD、PhyParts分母、treePL参数、默认值及用户界面均不以本轮重构为由改变。
协作执行仍按同一生成器次序推进，24ms执行预算和8ms暂停语义不变。

## 验收和边界

实际命令、构建ID、失败及修复记录、退出码和最终状态见同阶段02_验证记录；验收结果以最终verification.json为准，不以本文件或目录存在为准。
拆分过程中真实Dating导入暴露了标签修复生成器缺少局部上下文的问题，已写直接接口失败反例并修复；历史失败日志保留。
主文件仍有8,418行；控制器、嵌套历史状态以及其他渲染器尚未全部拆出。不能宣称未来修改零风险、跨平台已验收或软件可公开发行。
