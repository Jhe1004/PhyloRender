# 107 全软件界面组件统一

## 用户可见变化

- 普通树、Dating树、基因树—物种树冲突图和双树冲突对照中的有界数值参数统一为“减号／数字输入／加号”。
- 原来带滑块、重复数值和“精确输入”的大控件改为同一紧凑样式；云层透明度、抖动、饼图半径、HPD透明度与粗细等历史独立滑块也使用同一入口。
- 可展开的帮助统一显示问号；普通提示、状态和错误分别沿用统一视觉语义。
- 允许空白表示“未设置”的年龄边界仍保留普通数字输入，避免空白被错误改成0。

## 实现边界

- 新增`ui/numeric-controls.js`，只接收显式DOM端口和控件清单，创建统一编辑器并向原控件转发input/change事件。
- 原控件ID、配置字段、参数范围、步长、默认值和单位不变。隐藏range继续作为兼容数据源；网页和MCP仍共用原配置与渲染路径。
- app.js只保留接线与兼容委托；新模块已登记架构清单、浏览器加载、静态服务、构建指纹和Docker既有ui目录覆盖。

## 不变项

- 原始树、拓扑、分支长度、支持率、年龄、HPD、样品身份、PhyParts统计和treePL行为不变。
- SVG和PNG导出内容不因工作台样式变化而改变。
- 本阶段不部署、不推送、不重启共享服务，也不生成图文报告。
