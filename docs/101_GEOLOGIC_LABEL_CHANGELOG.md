# 101阶段：地质年代标签与缩写说明

从100号已验收源码建立独立副本。本轮只整理Dating树和云树共用的地质年代文字，不修改地质边界年龄、配色、树的时间、拓扑、HPD、样品名称或科学统计。

## 用户可见规则

- 每个当前时间范围内的年代或世色块都产生非空文字。
- 宽度足够时显示英文全称；放不下时按现有只读年代表选用短缩写或最短缩写。即使Holocene等色块极窄，也不再返回空字符。
- 只要图内使用了缩写，时间轴旁就以英文列出 `缩写 = 全称`，例如 `Q = Quaternary`、`Pst. = Pleistocene`、`H = Holocene`。同一缩写只说明一次。
- 上、下时间轴及Dating树／云树共用规则。用户调大字号或改变画布宽度后，说明条目和上方留白重新按实际缩写数量计算。

## 模块边界

`render/time-background.js`是唯一选词与绘制实现。它返回非空标签、汇总实际缩写，并绘制英文说明。`render/time-tree.js`和`render/cloud-tree.js`只读取共用的缩写条数留出空间，没有新建工作区私有算法。`core/time-display.js`的边界、名称、缩写和配色数值未改。

## 强制验收

直接反例检查极窄区间不得返回空字符，并要求每个缩写都有全称说明。真实浏览器验收覆盖Dating树和云树、独立字号、大字号、三种时间单位、网页／MCP一致、英文画布及未重跑treePL／PhyParts。必须再跑基础门禁、完整集成、原生科学专项、影响图件的限定差异对照和HTML报告实测。

本轮不部署、推送、重启共享服务，不新增Linux／Windows／Docker／安装包验收或许可结论。88号历史PNG差异根因仍未处理。
