# 满支持绘图使用当前显示精度（2026-11-02）

用户明确要求：99.99 等支持率在当前小数位设置下舍入为 100 时，
按满支持率绘制，而不继续标一个 100。概率列舍入为 1 时同样处理。
这替换此前“满支持始终按原始值判断”的显示契约，不是科学输入变更。

满支持分类和数值格式化统一由 core/support-values 使用同一个数值格式化
函数；app 仅传入当前精度，网页与 MCP 共用。默认一位小数时，99.99
和 0.9999 视为满支持；两位小数时，99.99 仍为非满支持。“保持原值”
模式使用未舍入数值。所有满支持样式（粗枝、圆点、数字、隐藏、星号）
共用此规则；用户选择数字样式时仍显示满值数字。

主树加附加来源及复合列必须所有所需值都存在、都达到各自量纲的满值，
才作为满支持；部分满值或未匹配来源仍为非满支持。双树比较按各自
所选字段和量纲应用同一规则。Dating 继续不显示支持率；云图的冲突
统计、低支持率阈值、分析输入和缓存不使用显示舍入。原始树、数值、
样品身份、枝长和匹配键均不改写，粗体开关的规则保持不变。
