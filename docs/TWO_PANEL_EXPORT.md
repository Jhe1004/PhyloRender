# 上下两图导出契约

普通树和 Dating 树过长时，PhyloRender 可以输出一张完整树，或最多两张自然高度的树图。

1. 只拆一次，绝不递归生成第三张图。
2. 第二张图必须是一个完整内部节点及其全部后代，也就是完整单系分支，不能从中间裁切。
3. 外类群保留在第一张主图中。
4. 第一张用英文占位末端 `Continued clade ... — see Panel 2` 表示被拆出的分支，该末端上方额外保留 0.75 个自动行距，不放松其他样品行。
5. 第二张的接入线从完整单系分支的根部延伸到图顶，顶端使用向上箭头和英文 `Continued from Panel 1` 明示承接关系；该图形标识不进入拓扑或枝长数据。
6. 两张图沿用当前字号、颜色、支持率、分组、比例尺和时间背景，不为适配 A4 纸张缩小。
7. 两张图必须使用完全相同的画布宽度；以较宽图为准扩展较窄图的空白画布，不拉伸树、文字或比例尺。
8. 两张图必须重新使用基于真实字形的自动紧凑样品间距，不继承或写入手动 `tip_spacing` / `tip_spacing_em`。
9. 普通树和 Dating 树支持该功能；云树和双树冲突图不支持。
10. 网页和 MCP 使用同一个 `core/tree-panels.js` 决策。MCP 的正式格式名是 `panels`，资源名是 `panel-1.svg/png` 和 `panel-2.svg/png`。
11. `a4` 仅作为旧客户端的弃用别名映射到 `panels`，不再生成 A4 页面文件。

验证至少覆盖：短树不拆、长树恰好两张、第二张完整后代集合、外类群不进入第二张、两张图宽度相同、自动紧凑间距、Dating 两张图共用完整时间轴、取消后恢复原画布，以及网页与 MCP 同一结果。
