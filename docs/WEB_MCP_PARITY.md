# 网页与 MCP 绘图一致性契约

本地版本：MCP 0.8.0，桥接 1.9.0，配置契约 1。

## 共用入口

网页和 MCP 使用同一个 `index.html`、`app.js` 和 SVG 导出器。
`figure-contract.js` 提供模式默认值和单位转换。
`agent-bridge.js` 将配置映射到真实网页控件。
MCP 不维护第二套绘图算法。

网页“输出”页面提供“导出绘图配置”和“载入绘图配置”。
MCP 的 `create_figure` 接受同一份配置。
配置包含原始树、数据、分组和显示参数。
请只与可信对象分享配置。
公开 MCP 报告只提供输入文件元数据和 SHA-256。

## 模式映射

| 网页栏目 | workspace | 必需输入 | 默认样品字号 |
| --- | --- | --- | --- |
| 普通树 | phylogeny | main_tree | 约 13.24 u |
| Dating 树 | time | main_tree | 约 15.88 u |
| 云树 | cloud | main_tree；云层另需 gene_trees | 约 15.88 u |
| 双树冲突对照 | conflict | main_tree + comparison_tree | 约 13.24 u |

四个工作区默认使用按实际字形与样品数计算的自动文字间距。密集树可见空隙接近1 px，稀疏树保留少量空隙。
Dating 树和云树的分组名称默认约 15.66 u，分组条默认统一对齐。
各模式默认使用较小姊妹群在上的顺序。
用户的显式配置覆盖默认值。

## 科学边界

- 时间树和云树物种树保留输入根。
- 普通树接受外类群定根；双树只指定主树外类群，副树按对应样品侧定根。
- 双树连线优化只旋转副树姐妹分支，不改变其无根拓扑。
- 输入的已定年物种树跳过 species treePL。
- 基因树继承物种树根年龄和相同后代集合的节点年龄。
- 内置JavaScript引擎完整统计四类计数；方法依据Smith et al. (2015)，但不是官方PhyParts。
- 两／四部分切换只改变显示。
- 内置冲突统计使用所有可比较基因树。
- 云层只使用末端完全匹配的 ML 子集。
- 非 ML 树不能进入 treePL 云层。
- 饼图的时间筛选和单节点隐藏不改变计数。
- 学名处理只改变显示，不改变样品身份。
- 分组可包含单个样品。

treePL在本工作流固定seed=1；版本、平台、浮点库仍可能造成差异，不能因此声称任意机器逐位相同。
本轮共有类群年龄约束明确为display_alignment，不是独立估计基因共祖时间。
构建指纹见导出SVG的phylorender-build元数据和MCP报告provenance；系统字体见font_portability。
字体或饼图显示模式编辑复用科学分析，不再次调用内置冲突统计或treePL；输入/科学参数变化会使缓存失效。
当前后台明确设置 `seed=1`。
客户端要求后台报告同一个种子。
旧后台缺少该标记时，客户端停止定年。
此修改不改变输入树和校准规则。

## Agent 工作流

1. 读取 `phylorender://capabilities` 和配置 Schema。
2. 检查树类型和原始样品身份。
3. 确认输入枝长来源与时间单位。
4. 明确指定 `workspace`。
5. 调用 `create_figure`。
6. 保存 `figure_id` 和 `revision`。
7. 检查 QA 报告与原始图件。
8. 编辑前调用 `inspect_figure`。
9. 使用当前 `base_revision` 提交语义编辑。
10. 导出不可变版本中的 SVG／PNG。

云树可设置图层、透明度、树形、阶梯化和饼图显示。
饼图设置包括时间范围、半径和两／四部分。
`hidden_pies` 使用完整后代样品集合。
它不依赖临时 Node 编号。

双树设置包括样品集合策略、标题、支持率字段和主树顺序。
规范字段 `options.layout.tip_order` 只允许交换姐妹分支；旧 `primary_order` 仅作导入兼容。
它不能改变拓扑。
网页导出配置保留这些选择。

## 验证与限制

运行 `node --test tests/*.test.cjs`。
运行 `npm --prefix mcp-server test`。
运行 `npm --prefix mcp-server run test:parity`。

一致性测试通过网页上传文件。
它通过真实 MCP 协议生成图件。
它比较所有 SVG 图形元素、文字、字体和图层。
它排除非图形编辑属性和来源元数据。
它还检查网页配置重新载入。

相同输入、参数、字体和运行环境构成一致性的前提。
不同系统的字体和抗锯齿可能产生像素差异。
Arial 不内嵌；缺失时明确使用内嵌 Arimo。
不要把跨系统像素一致写成已验证结果。

面板宽度、缩放、滚动和菜单属于编辑器行为。
它们不改变科学图件。
上下两图只支持普通树和 Dating 树；网页与 MCP 都最多生成两张，第二张是完整单系分支。
默认预计算示例缺少完整原始输入。
它不能导出可重新计算的配置。
它仍可导出 SVG／PNG。

它不代表公网网页或 MCP 已更新。
