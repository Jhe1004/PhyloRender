## 1. 树文件解析、分类群身份解耦与无根分支匹配算法

### Newick 与 Nexus 安全解析
PhyloRender 通过确定性单遍词法分析器解析标准 Newick 与 Nexus 树文件，完整保留原始叶节点标识符、分支长度（遇到负值或非法数值直接报错拒绝，绝不静默归零）、内部节点标签以及方括号元数据注释（`[&...]`，如贝叶斯分化年龄与 95% 最高后验密度 HPD 区间）。针对 Nexus 输入，解析器在跟踪单双引号配对与嵌套方括号注释层深的同时，严格限定在 `TREES` 块边界内提取分类群映射表（`TRANSLATE`）和树定义，确保注释块或其他 Nexus 数据块中的数字或文本绝不会被误认为样品编号映射。当包含多棵树的 Nexus 文件或拼接多棵树的 Newick 文本被传入单树工作区时，程序会直接返回阻断性错误，要求用户或调用方先在外部选定或汇总出单棵一致树或最大分支可信度（MCC）树，绝不暗中默认读取第一条后验样本树。

### 原始分类群身份与格式化显示名称的解耦机制
在全部四个工作区中，每个末端节点均同时维护两套独立属性：直接提取自输入树文件的不可变原始标识符（raw taxon identifier），以及仅用于画布渲染的显示名称（display label）。跨树样品匹配、外群定根、基于最近共同祖先（MRCA）的分类群定义以及拓扑结构校验始终基于原始标识符执行。生成默认显示名称时，程序在首个包含数字的令牌（对应标本凭证号或测序登录号）之前将名称切分为学名前缀与编号后缀：学名前缀中的下划线转换为空格，而带有内部下划线的标本凭证号或序列号后缀（如 `2023080906_1` 或 `SRR21412921`）保持正体且原样保留。开启分类学名自动格式化后，拉丁属名及属下加词、种加词、种下加词自动斜体化，而分类阶元、开放命名鉴定词与杂交标记（`subsp.`、`ssp.`、`var.`、`subvar.`、`f.`、`forma`、`sp.`、`cf.`、`aff.`、`sect.`、`ser.` 及杂交符号 `×`）均保持正体；在默认开启的分类阶元缩写标准化模式下，非标准等级写法（如 `ssp.`/`subspecies`、`forma`/`fo.` 与 `variety`）会按命名法规在正体下统一规范为 `subsp.`、`f.` 与 `var.`。用户上传的自定义显示名映射表（支持 CSV、TSV、TXT 或 `.xlsx` 文件）在提交前校验每个原始名称必须唯一解析到当前树中已存在的末端且无冲突重复行（允许同种多份不同凭证标本共享相同的物种显示学名，其底层原始身份依然各自独立）；而在跨树分类群对齐与分支匹配阶段则执行严格的一对一身份核验，一旦树内两个不同末端碰撞到同一归一化键，程序立即报歧义错误拒绝导入。

### 跨推断方法的无根分支划分自动匹配
在普通系统发育树工作区中，一棵主树最多可配对 20 棵由不同推断方法生成的附加支持率树（例如将拼接法最大似然树与 ASTRAL 溯祖法物种树 Zhang et al., 2018 或贝叶斯多数一致树配对）。由于不同建树软件常输出无根树，或将树根置于不同的外群分支上，按有根后代集合匹配内部节点极易导致相同演化分支配对失败。为此，PhyloRender 在各棵树的归一化末端集合 $\mathcal{T}$ 上（自动对齐唯一匹配的 `out_` 或 `outgroup_` 前缀差异）按规范无根分类群划分（canonical unrooted bipartitions / splits）为内部树枝建立索引。移除树上任意一条内部树枝 $e$ 会将其 $N$ 个末端切分为两个非空互补子集 $A_e$ 与 $B_e = \mathcal{T} \setminus A_e$（忽略 $|A_e| < 2$ 或 $|B_e| < 2$ 的末端平凡划分）。程序选取元素较少的一侧子集（当 $|A_e| = |B_e|$ 时选取排序后字典序靠前的一侧子集）作为该内部树枝的规范无根划分键。对于构建在相同分类群集合 $\mathcal{T}$ 上的多棵树，该划分键与树根位置完全无关，无论各输入树如何定根都能自动精确配对相同分支。

### 支持率量纲核验与满支持/低支持分类规则
渲染前，程序对每棵源树的每一个斜杠分列独立执行支持率量纲校验。在自动识别模式下，仅当某一列包含大于 $1$ 的数值且不含任何严格落在 $(0, 1)$ 内的小数时，才判定为百分数量纲（$[0, 100]$）；只要列内出现任何落在 $(0, 1)$ 内的小数（即便同列混有大于 $1$ 的数值），或仅含 `0` 与 `1` 而无大于 $1$ 的数值，程序均拒绝歧义自动识别并要求显式指定单位（`probability` 或 `percent`）。低支持率掩码（将严格低于设定阈值的支持率替换为短横线 `–`）与基因树冲突统计阈值始终基于未舍入的原始数值判定；而“满支持”视觉样式（如以 $2.5\times$ 线宽代替重复打印 `100/1.00` 数字）则要求该分支在所有已配置的支持率来源上均存在有效值，且在当前显示小数位数下均达到各自满值（百分数达到 `100`，概率达到 `1`；原字符串 `original` 模式不执行舍入）。

## 2. 评分引导的节点标签自动放置与带断口引线路由算法

### 内部设计像素坐标系、排布顺序与局部障碍物包络
全部几何排版与防碰撞优化计算均在固定宽度为 $1,511\text{ px}$ 的内部设计画布上执行，排版完成后按精确比例因子 $1,000 / 1,511 \approx 0.6618$ 线性缩放投影至 PhyloRender 统一的 $1,000$ 绘图单位（`u`）标准画幅（第 2 与第 3 节中的所有像素常数均指该 $1,511\text{-px}$ 内部设计空间）。在普通系统发育树工作区中，程序优先排布包含低支持率短横线标记（`–`）的标签，随后再排布纯数字标签（各组内部保持树遍历顺序），使紧凑阈值符号先占据分叉点紧邻空隙，再为较宽的复合数值字符串（如 `98/0.99`）规划空间与引线；在分化时间树与双树对照图工作区中，候选节点按画布纵向坐标从上到下依次排布。对于坐标为 $(x_0, y_0)$ 的内部节点，求解器在向外延伸 $R = 192\text{ px}$（双树对照图为 $96\text{ px}$）外加首选标签宽高与 $8\text{ px}$ 边距的局部搜索框内，收集全部树枝线段、内部节点圆点、已渲染的末端名称框以及此前已放置的节点标签与引线线段，构成局部障碍物包络。

### 跨几何走廊的多字号候选位置生成
不同于固定偏移打印或盲目缩小全图字号的做法，引擎从首选字号 $s_{\text{pref}}$ 开始按 $1\text{ px}$ 步长递减至可读字号下限 $s_{\text{min}}$，依次评估离散可读字号序列 $s \in \{s_{\text{pref}}, s_{\text{pref}}-1, \dots, s_{\text{min}}\}$。在每个候选字号 $s$ 下，程序在真实 SVG 画布上测量标签文本的字形包围盒 $(w, h)$，并围绕 $(x_0, y_0)$ 生成三类候选矩形位点：第一类为方向辐射环，围绕六个主方向（正左、左下、左上、正右、右上、右下）从紧邻净空（$4\text{ px}$）起按 $8$ 至 $192\text{ px}$ 的径向距离环采样（辅以正交网格与上下方向偏移），并优先偏好分叉点祖先把柄侧空位；第二类为树枝走廊槽位，将局部竖直树枝左右两侧净空边缘（$\pm 3.05\text{ px}$）及平行竖直树枝之间的走廊中线，与相邻水平树枝之间开放垂直空隙（上下各留 $3.25\text{ px}$ 护栏）的上缘、中点、下缘及节点中心邻近偏移组合；第三类为障碍物边界槽位，在已放置邻近标签上下外侧（留出 $2.05\text{ px}$ 垂直护栏）按水平偏移采样，随后按空间距离环与象限扇区抽样进入路由评分。

### 基于 Liang–Barsky 裁剪算法的精确碰撞过滤
进入路由评分前，所有候选矩形均须通过精确几何碰撞过滤。外扩安全边距后的候选文本框（对树枝外扩 $3\text{ px}$、对其他文本框外扩 $2\text{ px}$、对已有引线外扩 $1.5\text{ px}$、对异源内部节点保持 $\max(3, r_{\text{node}}) + 1\text{ px}$ 净空、对画布四边留出 $4\text{ px}$ 边距）与水平、竖直及斜向线段的相交检测统一采用参数化 Liang–Barsky 线段裁剪算法精确求解，任何碰撞候选均被立即淘汰。

### 字号与引线路由联合代价函数及多轮全局墨迹精修
对每个零碰撞的合法候选矩形 $\mathbf{r}$（字号 $s$），PhyloRender 评估从 $(x_0, y_0)$ 指向标签可见近侧边缘中心附着点的直线虚线引线。字号大小与引线几何在单一可加联合目标函数中同步竞争最优解：
$$C(s, \mathbf{r}) = C_{\text{font}}(s) + C_{\text{route}}(\mathbf{r}) + C_{\text{pos}}(\mathbf{r})$$
其中字号缩小惩罚 $C_{\text{font}}(s)$ 随字号从 $s_{\text{pref}}$ 向 $s_{\text{min}}$ 递减呈二次增长：
$$C_{\text{font}}(s) = 20\,u_s + 25\,u_s^2, \quad u_s = \frac{\max(0,\, 1 - s / s_{\text{pref}})}{0.05}$$
当启用节点箭头引线时，普通树与时间树中 $C_{\text{pos}}(\mathbf{r}) = 0$（双树对照图中朝树内侧偏移附加 $18$ 的侧向惩罚；关闭引线时 $C_{\text{pos}}$ 对非紧邻漂移施加惩罚），任何穿过其他文字框的引线均被禁止（$C_{\text{route}} = \infty$）。合法引线的路由代价综合量化拓扑交叉、引线长度与角度偏离：
$$C_{\text{route}}(\mathbf{r}) = 2800\,n_{\text{node}} + 650\,n_{\text{leader}} + 180\,n_{\text{branch}} + 10\,u_L + 10\,u_L^2 + 300\,\max(0, u_L - 2)^2 + 6\left(\frac{|\theta - 45^\circ|}{15^\circ}\right)^2 + 100\,E(\theta, L)$$
上式中，$L$ 为设计像素下的引线长度，$u_L = L / L_{\min}$（目标最小引线长度 $L_{\min} = 14\text{ px}$）；$\theta \in [0^\circ, 90^\circ]$ 为引线与水平轴夹角（理想对角线为 $45^\circ$，偏好窗口为 $20^\circ\text{--}80^\circ$）；越界惩罚项 $E(\theta, L) = \max(0, 19.75^\circ - \theta) + \max(0, \theta - 80.25^\circ) + \max(0, 13.9 - L)$ 同时约束超出偏好角度窗口与低于最小长度下限的引线（含 $0.25^\circ$ 与 $0.1\text{ px}$ 浮点容差）；$n_{\text{branch}}$、$n_{\text{leader}}$ 与 $n_{\text{node}}$ 分别统计跨过树枝、跨过已有引线及侵入异源节点净空的次数。引擎选取最小化 $C(s, \mathbf{r})$ 的组合 $(s^*, \mathbf{r}^*)$（$10^{-6}$ 容差内优先保留较大字号）。完成初始逐节点排布与 `getBBox` 校验后，普通树与时间树还基于字形墨迹框执行多轮全局离散精修（碰撞修复、单点与成对标签槽位互换、字号恢复及交叉引线解耦）。凡引线跨过树枝线段（$n_{\text{branch}} > 0$）时，渲染器在树枝层上方、$1.15\text{ px}$ 虚线引线底层预置一条宽 $3.8\text{ px}$（不透明度 $0.97$）的白色光晕底线，在每处跨枝交点形成清晰的白色视觉过桥断口。

## 3. 层级分类括号、ICS 地质年代表自适应、竖版比例平衡与单系双面板拆分算法

### 多层分类括号推导与同列竖向对齐
分类群或谱系高亮通过指定一个或多个原始末端标识符按语义定义（单个末端高亮单支物种，两个及以上末端由其 MRCA 锁定单系演化支）。PhyloRender 先按所含末端数升序排列各分组，再根据后代末端集合的严格真子集包含关系自动推导嵌套层级：最内层分支（层级 $t = 0$）为其后代树枝和末端名称着色，外包分支依次分配至外层（$t = 1, 2, \dots$）。在自动线型模式下，内层 $t = 0$ 采用实线括号，第一外层 $t = 1$ 采用端帽锁定的等步长虚线括号，更高阶外层（$t \ge 2$）采用实线端帽点划线括号。同时也支持显式指定层级编号（$t \in \{0, \dots, 5\}$），使单型亚科及其唯一族可在同一节点上挂载内外两道括号。组名字号默认比当前末端字号大 $3\text{ u}$。只要图中包含两个及以上层级（或末端本身右对齐，如时间树与云图），同一层级 $t$ 的所有括号竖线均严格锁定在共享水平坐标 $X_t$ 上排成竖列；若同一竖列内两个竖排组名纵向间距不足 $8\text{ px}$，程序仅将碰撞文字按 $\text{round}(1.35\, s_{\text{clade}})$ 步长向右平移至相邻文字泳道，括号竖线始终保持严格共线。

### 官方 ICS 地质年代表与窄格自适应缩字
分化时间树与云图工作区共用同一套地质年代背景与时间轴渲染器，固定内置国际地层委员会（ICS `2026/06` 版）官方完整 `0–4567 Ma` 年代地层表（Cohen et al., 2013），涵盖显生宙各纪、世及前寒武纪正式代与纪。对当前可见的每个地质区间 $[t_{\text{young}}, t_{\text{old}}]$（格宽 $W_{\text{cell}}$），拟合器在默认纪或世字号 $s_0$（含格内水平边距）下依次测试完整英文名（如 `Pleistocene`）、标准短缩写（`Pst.`）与最短缩写（`Ps`）。当靠近现今的窄区间（如 $100\text{ Ma}$ 时间轴上的第四纪 `Q`、上新世 `Pl` 或更新世 `Ps`）在 $s_0$ 下连最短缩写也放不下时，程序仅对该格的最短缩写按 $s_{\text{fit}} = \min\bigl(s_0,\, s_0 \cdot W_{\text{avail}} / W_{\text{natural}}\bigr)$（其中可用净宽 $W_{\text{avail}} = W_{\text{cell}} - \min(4, \max(2, 0.18\,W_{\text{cell}}))$，以 $0.25\text{ px}$ 步进实测微调）单独缩小字号。可用净宽不足或缩写字号需缩至低于 $4\text{ px}$ 可读下限的微观细缝保留彩色地层色带与悬停元数据而省略印刷文字，防止文字跨格溢出或依赖外置引线。

### 基于中位数的末端名称限宽与竖版行距自动舒展
为防止少数超长分类群名或凭证号挤压树枝横向空间，PhyloRender 测量全图可见末端名称的自然字宽 $\{w_1, \dots, w_N\}$ 并取中位数 $W_{\text{med}}$，仅对超出 $1.25\,W_{\text{med}}$ 的超长标签通过 SVG `textLength`（`spacingAndGlyphs`）将宽度限制在 $1.25\,W_{\text{med}}$，其余名称保持自然比例且不截断字符或改变字高。纵向布局上，普通树、分化时间树与云图默认启用竖版比例平衡模型：在稀疏树（$N \le 80$）上增大末端行距使整图高宽比趋近 $1.25$，同时受 $\min(3\text{ em},\, 72\text{ px})$（$\approx 47.65\text{ u}$）双重上限约束；当末端数处于 $80 < N < 120$ 时，通过三次 Hermite 平滑权重 $w(p) = 1 - 3p^2 + 2p^3$（$p = \text{clamp}((N - 80)/40, 0, 1)$）平滑回到紧凑行距基线。

### 单系分支自动双面板拆分
对于超出单页容量（$N > 76$ 个末端）的高大普通树与分化时间树，双面板导出在完成外群定根与阶梯化排序后执行一次单系拆分。所有外群末端均被标记保护以确保树根与外群留在面板 1。在不含外群的非根内部节点中，拆分器检索使面板 1 至少保留 $N_{\min} = \max\bigl(2,\, \min(38, \lceil 0.25 N \rceil)\bigr)$ 个概览末端的单系分支（规模为 $K$）；对满足 $K \ge N - 75$（即计入 1 行承接提示后面板 1 总行数 $\le 76$）的候选分支，优先选取最靠近底部的分支，若嵌套父子单系支共享最底端叶节点则选取满足容量的最小冠群 $K$ 以尽量保留面板 1 的主干概览。面板 1 将被拆出的子树替换为带承接箭头的单行提示以指明转入面板 2 的 $K$ 样品分支（普通树保留真实主干枝长，分化时间树则延伸至现今 $0\text{ Ma}$ 时间线）；面板 2 在完全相同的 $1,000\text{-u}$ 画幅宽度与字号比例下完整绘出该单系冠群，并自动继承跨越拆分节点的外层分类括号。

## 4. 双树对照图姐妹分支解缠绕算法

### 一对一分类群核验与折叠节点枝长累加机制
在双树对照图（Tanglegram）工作区中，左侧参考主树 $T_1$ 与右侧对照树 $T_2$ 按归一化后的原始末端标识符（剥离外层引号、合并连续空白与下划线并统一转为小写，拒绝树内重复碰撞）执行一对一比对。若两侧末端集合 $\mathcal{L}(T_1)$ 与 $\mathcal{L}(T_2)$ 不完全一致，样品数相等但名称失配的情形优先提示核查源树拼写，样品集合不同的情形则要求显式指定保留策略：`intersection` 将两棵树裁剪至共有交集 $\mathcal{L}(T_1) \cap \mathcal{L}(T_2)$ 并在折叠非根二度单传节点时精确累加连续枝长以保持分类群间演化路径距离不变，`union` 则保留两侧全部末端并仅在共有样品间绘制连线。

### 对照树单遍中位数秩姐妹分支旋转
为严格尊重用户选定的主树参考顺序，PhyloRender 保持左侧主树 $T_1$ 的纵向排列固定不变（由其阶梯化设置或手动右键翻转决定），仅对右侧对照树 $T_2$ 旋转姐妹分支。设 $T_1$ 中每个保留末端 $t$ 的纵向行序号为 $r_1(t) \in \{0, 1, \dots, |\mathcal{L}(T_1)| - 1\}$。程序对右树 $T_2$ 自底向上执行后序遍历，为每个内部节点 $u$ 的子分支 $c_i$ 赋予其所含共有末端在左树中行序号的中位数：
$$m(c_i) = \text{median}\bigl\{\, r_1(t) \;\big|\; t \in \mathcal{L}(c_i) \cap \mathcal{L}_{\text{shared}} \,\bigr\}$$
（`union` 模式下若某子分支不含共有末端则令 $m(c_i) = +\infty$，使其排在含共有末端的姐妹分支之后并保留原相对顺序）。将 $T_2$ 各内部节点的子分支按 $m(c_i)$ 升序重排（平局保持原序）得到保持拓扑不变的候选构型；当且仅当重排后的共有样品连线逆序交叉总数 $K$ 不劣于重排前基线时采纳该重排结果：
$$K = \sum_{1 \le i < j \le M} \mathbb{I}\bigl(r_2(\pi_i) > r_2(\pi_j)\bigr)$$
其中 $(\pi_1, \dots, \pi_M)$ 为左树共有样品从上到下的序列，$r_2(\pi_i)$ 为样品 $\pi_i$ 在右树中的纵向行序秩。共有样品跨越净宽为 $W = \text{right} - \text{left}$ 的中央走廊，由水平进出文字列边缘的三次贝塞尔曲线（`M x1 y1 L left y1 C left+0.36W y1, right-0.36W y2, right y2 L x2 y2`）连接，确保连线绝不穿过文字。

## 5. 内置基因树冲突统计、惩罚似然视觉对齐与云图渲染算法

### 基因树外群定根与顺序不变的四分类冲突统计
在云图（Cloudogram）工作区中，有根物种树 $T_S$（物种集 $\mathcal{S}$，支持最高 $1,000$ 个物种）与基因树集合 $\{G_1, \dots, G_M\}$（单次最高 $20,000$ 棵）联合分析。在默认外群定根策略下，给定对应物种树根节点一侧完整子分支的外群集合 $\mathcal{O}_{\text{root}}$，只要无根基因树 $G_k$ 中观测到的外群子集 $\mathcal{O}_{\text{root}} \cap \mathcal{L}(G_k)$ 非空、内群至少含两个物种且在 $G_k$ 中构成单系分离边，即自动在该分离边上定根；不符合条件的个别基因树逐棵记入审计报告并排除，不丢弃其余数据。

依据 Smith et al.（2015），物种树内部节点 $v$ 定义了有根内群 $I_v \subset \mathcal{S}$ 与外部集合 $O_v = \mathcal{S} \setminus I_v$。对每棵可比有根基因树 $G_k$（观测物种集 $S_k \subseteq \mathcal{S}$ 编码为任意精度 `BigInt` 位掩码），令 $I_{v,k} = I_v \cap S_k$ 与 $O_{v,k} = O_v \cap S_k$ 为节点 $v$ 在 $S_k$ 上的投影。给定支持率阈值 $\tau \in [0, 0.999]$，当 $\tau = 0$（默认不按支持率过滤）时令 $\mathcal{C}(G_k, 0)$ 包含 $G_k$ 全部非平凡内部有根分支（含未标支持率的分支）；当 $\tau > 0$ 时令 $\mathcal{C}(G_k, \tau)$ 仅包含带有数值支持率且严格大于 $\tau$ 的内部有根分支。在节点 $v$ 处，若 $|I_{v,k}| < 2$ 或 $|O_{v,k}| < 1$，或 $\mathcal{C}(G_k, \tau)$ 中既无匹配分支也无冲突分支，则 $G_k$ 计为**无信息（uninformative）**。当基因树缺失部分物种导致物种树多个嵌套祖先节点在 $S_k$ 上投影为同一子集 $I_{v,k}$ 时，程序将该投影唯一归属给原始物种树叶节点数 $|I_v|$ 最小（最特异/最浅层）的物种树节点：仅当 $I_{v,k} \in \mathcal{C}(G_k, \tau)$ 且节点 $v$ 为该唯一最特异归属节点时计为**一致（concordant）**（同投影的更深层主干节点记为无信息，防止缺失物种重复虚增深层一致性计数）；而只要 $\mathcal{C}(G_k, \tau)$ 中存在与 $I_{v,k}$ 拓扑不兼容的分支 $C \subset S_k$（同时满足 $C \cap I_{v,k} \ne \emptyset$、$I_{v,k} \setminus C \ne \emptyset$ 与 $C \cap O_{v,k} \ne \emptyset$），即计为**冲突（conflicting）**。

完整物种取样时，冲突分支按位掩码相等直接分离出**主替代冲突（dominant alternative）**与**其余替代冲突（remaining alternatives）**。存在物种缺失（$S_k \subset \mathcal{S}$）时，为消除输入文件顺序依赖，PhyloRender 将每个观测冲突分支记为带观测作用域的二元组 $(C, S_k)$，并对每个观测内群掩码 $C^*$ 汇集直接观测到它的全部作用域并集 $S^* = \bigcup_{(C^*, S_j)} S_j$ 构成候选分支 $(C^*, S^*)$；部分冲突分支 $(C, S_k)$ 仅在同时满足 $S_k \subseteq S^*$、$C = C^* \cap S_k$ 且 $(S_k \setminus C) \subseteq (S^* \setminus C^*)$ 时向 $(C^*, S^*)$ 计一票（每棵冲突基因树对同一候选至多计一票）。取全候选最大合并票数作为 $n_{\text{dom}}(v)$，令 $n_{\text{other}}(v) = n_{\text{conflict}}(v) - n_{\text{dom}}(v)$，即可严格保证四类统计结果与基因树输入顺序无关。

### 惩罚似然超度量视觉对齐（连续逻辑斯蒂比例参数化与解析梯度 L-BFGS）
为在时间轴上叠绘基因树云层，PhyloRender 筛选包含完整物种集合（$\mathcal{L}(G_k) = \mathcal{S}$）且具非负有效 ML 替换枝长的可比基因树（排除 $\ge 80\%$ 末端枝长为零的退化树，总叠加节点上限为 $30,000$ 且绝不随机抽样），将其缩放对齐至物种树共有分支年龄（未定年 ML 物种树亦可由同一求解器按指定根年龄完成超度量缩放）。依据 Sanderson（2002）与 Smith 和 O'Meara（2012），非根节点 $i \in \{1, \dots, |E|\}$（父节点 $p(i)$）的 ML 枝长 $b_i \ge 0$ 转化为有效替换计数 $c_i = \text{round}\bigl(\max(b_i, 1/N_{\text{sites}}) \cdot N_{\text{sites}}\bigr)$（$N_{\text{sites}} = 10^8$，平滑权重 $\lambda = 100$）。末端固定 $t_i = 0$，根节点固定 $t_0 = T_{\text{root}}$，与物种树共享相同后代物种集的共有内部节点锁定为对应物种树年龄 $t_i = t_i^{\text{fixed}}$。速率平滑泊松惩罚似然目标函数为：
$$\mathcal{J}(\mathbf{r}, \mathbf{t}) = \frac{1}{N_{\text{sites}}} \left[ \sum_{i=1}^{|E|} \bigl(r_i d_i - c_i \ln(r_i d_i)\bigr) + \lambda \sum_{p(i) \ne 0} (r_i - r_{p(i)})^2 + \frac{\lambda}{k_0} \sum_{j \in \text{children}(0)} (r_j - \bar{r}_0)^2 \right]$$
其中 $r_i > 0$ 为分支速率，$d_i = t_{p(i)} - t_i > 0$ 为分支时长，$k_0$ 为根分叉度，$\bar{r}_0 = \frac{1}{k_0}\sum_{j \in \text{children}(0)} r_j$。

为免除外部 C++ `ADOL-C` 与 `NLopt` 依赖，求解器将有界变量映射至无约束向量 $\mathbf{x} \in \mathbb{R}^{1 + |E| + |V_{\text{free}}|}$。分支速率在对数空间参数化为 $r_i = \exp\bigl(\text{clamp}(x_0 + \alpha\, x_i,\, -45, 45)\bigr)$（步长因子 $\alpha$ 由总有效替换数与初始全树总分支时长归一化导出）。对每个自由内部节点 $u \in V_{\text{free}}$，后序遍历先求得其下方最老固定后代年龄下界 $L_u = \max\bigl(\{0\} \cup \{\, t_w^{\text{fixed}} \mid w \in \text{desc}(u) \,\}\bigr)$，前序遍历再将 $t_u$ 表示为父节点年龄 $t_{p(u)}$ 与 $L_u$ 间的逻辑斯蒂插值：
$$t_u = L_u + \sigma(z_u)\bigl(t_{p(u)} - L_u\bigr), \quad \sigma(z_u) = \frac{1}{1 + e^{-z_u}}, \quad z_u \in [-32, 32]$$
在双精度浮点运算中严格保持 $0 < \sigma(z_u) < 1$，确保零枝长或极短辐射枝上的时长 $d_i > 0$ 永不越界。$\mathcal{O}(|V|)$ 精确解析梯度经一次后序反向传播求得：
$$\frac{\partial \mathcal{J}}{\partial z_u} = \frac{\partial \mathcal{J}}{\partial t_u}\bigl(t_{p(u)} - L_u\bigr)\sigma(z_u)\bigl(1 - \sigma(z_u)\bigr), \quad \frac{\partial \mathcal{J}}{\partial t_{p(u)}} \leftarrow \frac{\partial \mathcal{J}}{\partial t_{p(u)}} + \frac{\partial \mathcal{J}}{\partial t_u}\sigma(z_u)$$
并由内置确定性 L-BFGS 求解器（历史步数 $m = 16$、Barzilai–Borwein 初始 Hessian 缩放、参数 $c_1 = 10^{-4}$ 与 $c_2 = 0.9$ 的标准 Wolfe 线搜索及梯度无穷范数容差 $10^{-11}$）收敛求解。

### 云图共有节点纵向锚定、物种树 MRCA 着色与确定性曲率抖动
排布基因树云层时，与物种树共享相同后代物种集合的共有内部节点直接锚定至物种树对应节点的精确纵向坐标（$Y$）；基因树独有的局部冲突节点以子节点纵向均值为初值，并在纵向跨度达到或超过 $3$ 行时经两遍分位点局部扫描最小化边交叉与近距拥挤惩罚。每条基因分支通过二进制倍增最近共同祖先表在 $\mathcal{O}(\log N)$ 时间内查询其后代物种在物种树上的 MRCA 节点并继承所属分组颜色（基部未着色主干保持中性灰）。开启可选云层抖动（整数强度 $1\text{--}100$，默认 $0$）时，非零跨度基因分支绘为三次贝塞尔曲线，控制点 $(x_p + \Delta x/3,\, y_p + \Delta y/3 + \delta_y)$ 与 $(x_p + 2\Delta x/3,\, y_p + 2\Delta y/3 + \delta_y)$ 的纵向偏移 $\delta_y$ 由根、父、子拓扑签名与树序号经 32 位 FNV-1a 散列确定性生成，使强度 $100$ 时曲线中点的峰值偏转振幅上限恰好为 $0.5$ 倍行距（对应控制点偏移上限 $|\delta_y| \le \frac{2}{3}$ 倍行距并钳制于绘图区边界内），所有节点端点与时间坐标保持不变。

## 6. 共享无头渲染运行时、乐观并发控制与原子事务状态一致性

### 跨浏览器与程序化接口的单引擎等价架构
为确保交互式会话与自动化流程在几何排版、字形测量与数据校验上完全一致，PhyloRender 不为网页端与模型上下文协议（MCP；Anthropic, 2024）服务维护两套独立绘图代码，而是在受管无头 Chromium 运行时中直接加载并执行与浏览器工作台完全相同的模块化 JavaScript 解析、科学准备、协作排版调度及 SVG/PNG 序列化代码，统一遵循 $1,000\text{-u}$ 共享图件契约。大规模基因树解析、冲突统计与惩罚似然对齐在专属 Web Workers 中运行，遇到取消、超时或页面关闭时立即终止回收；服务端有界任务队列与进程组级监管机制则统一管控本地辅助服务与可选原生工具，杜绝孤儿后台进程残留。

### 不可变修订链、乐观并发控制与原子事务回滚
服务端管理的每张图件均维护一条仅追加的不可变修订链（`revision 1, 2, ...`），持久记录经校验的图件规格、全部原始输入树与数据表的 SHA-256 散列、版面碰撞诊断及拓扑指纹。程序化修改请求在单图串行队列中强制核验调用方传入的 `base_revision`，过期版本号立即以结构化 `REVISION_CONFLICT` 错误拒绝，防止静默覆盖并发更新。在两端运行时中，完整配置导入与批量编辑均以原子事务执行：浏览器端在入口捕获完整的文档模型、界面控件与缓存快照并在任一步骤失败时完整恢复；MCP 存储层则在临时目录完成全部校验与无头渲染后，仅通过原子目录重命名一次性提交新版本。
