# 106 Dating 导入后保持展开

## 用户可见变化

- 用户在已经展开的“导入树”栏目中成功选择 Dating 树文件后，该栏目不再自动关闭。
- 步骤 2“确定时间单位和年龄来源”继续显示在步骤 1 下方，无需再次点击“导入树”。
- 其他设置栏目仍按原来的页面进入规则收起；普通树行为不变。

## 原因与修复边界

导入成功会刷新当前工作台页面。旧代码在刷新时无条件关闭当前页全部栏目，因此也关闭了正在进行的 Dating 两步流程。本阶段只为已经打开的 Dating 主导入栏目保留原展开状态，没有强制打开未由用户展开的栏目。

## 不变项

- 文件读取、Newick/Nexus 解析、输入验证、导入事务和失败回滚不变。
- 时间单位、年龄来源、节点年龄与 HPD 的控件、默认值和数据含义不变。
- 原始树、拓扑、年龄、HPD、样品名称、布局、网页/MCP配置和导出图件不变。

## 验证要求

- 先用真实 Dating 文件入口证明旧代码在成功导入后关闭栏目，再证明修复后栏目保持展开且步骤 2 可见。
- 四工作区导航、普通栏目收起、窄工作台和现有输入事件继续通过。
- 旧/新 SVG 除构建 metadata 外全属性一致，完整 PNG 字节一致。
- 完整浏览器/MCP、原生 treePL/PhyParts 和导入稳定性门禁通过。
