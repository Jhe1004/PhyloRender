# 103阶段：极窄年代全称箭头标注

本阶段从102号已验收源码建立独立副本。用户指出外置的`H = Holocene`仍与相邻的`Ps`挤在一起，视觉上像`PsH`。本轮只调整极窄年代的外置文字。

## 新规则

- 色块可以容纳全称或缩写时，仍在色块内显示，与102号一致。
- 色块连最短缩写也放不下时，使用矢量箭头指向只显示英文全称的外置文字，例如箭头后显示`Holocene`。
- 外置文字不再显示`H =`，也不再重复画颜色方块；原有细引导线继续把文字与真实色块关联。
- 年代边界、色块宽度、颜色、树坐标、年龄、HPD、拓扑、样品名称和统计均不改变。
- Dating树和基因树—物种树冲突图共用`render/time-background.js`；网页和MCP使用同一条渲染路径。

## 验收边界

直接模块测试必须先证明旧代码仍输出`H = Holocene`，再证明新代码以矢量箭头指向`Holocene`且没有以`H =`开头的外置文字。真实浏览器和MCP专项同时覆盖Dating树、云树、大字号、英文画布和网页／MCP一致性。图件对照只允许地质年代层的箭头和文字发生本次明确变化；地质色块几何和图件其他部分必须保持一致。
