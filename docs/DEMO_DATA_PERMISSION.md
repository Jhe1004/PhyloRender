# Existing demonstration-tree distribution permission

On 2026-10-30 (Asia/Shanghai), the project owner was asked whether they have the
right and agree to public distribution of the existing Ranunculaceae 173/58-tip
examples (`app.js`, `defaults/`) and the 27-tip Salicaceae StarBEAST3 Dating
example with PhyloRender. The owner explicitly answered:

> 同意公开这些现有演示树

This records permission to include and publicly distribute those existing
software demonstration trees. The examples remain demonstrations, with their
original scientific values and provenance retained; the permission does not
establish new biological conclusions or replace a research citation.

This permission does not cover arbitrary AMD research files. The AMD files
retrieved during this audit are authorized for private testing, retained under
Git/Docker-ignored `mcp-server/var/`, and excluded from public distributions.
It also does not authorize publication of credentials, user-generated figures,
private configurations, unrelated research datasets or historical Git objects.

No separate general-purpose open-data license is inferred from this reply.
Retain this permission record with the relevant source examples and request
specific terms if a downstream data-reuse license is needed. The project's
GPL-3.0-or-later code license does not automatically relicense users' data.
