# 85阶段：双树冲突渲染模块化

基线为84阶段已验收源码。历史阶段、科学输入和共享运行服务不动；本轮是结构迁移，不改绘图算法、默认值或科学解释。

## 责任边界

- render/conflict-branches：矩形双树枝线、分组色、原值判定的满支持粗线及返回的几何线段。
- render/conflict-support：支持率条目、原候选生成/去重/分层采样顺序、字号评分、碰撞和箭头、标记与文字。逐候选yield继续提供取消边界。
- render/conflict-tree：双面板布局、样品名、实测文字边界、同名连线、支持率层、标题与分组图例。模块返回完整诊断，不写科学prepared对象。
- app：继续负责验证/准备/导入事务、样品字段选择与格式化、字体及名称回调、菜单/高亮、文档结果提交和中文反馈。

单次呈现传入字号、半径、箭头、标题和已解析的支持率快照。字号下限控制的界面回写保留在原来的几何测量之后、支持率排版之前，避免原画布字体或行距被提前改变。
publishSize也保留在候选搜索前。生成器关闭会经yield*关闭支持率搜索；没有半成品诊断提交。导入失败由原有完整事务恢复，不在新模块另造部分回滚。

主文件从7,604行减少到7,149行。上限由7,610收紧为7,155行。新增模块登记浏览器加载、架构清单、构建目录覆盖；已有静态白名单及Docker COPY包含render目录，未构建镜像。
