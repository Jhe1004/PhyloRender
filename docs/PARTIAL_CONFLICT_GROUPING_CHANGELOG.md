# 部分样品基因树的主冲突计数修复（2026-11-03）

## 问题与边界

v1 对冲突分支使用首次匹配、箱内两两直接包含的贪心规则。同一替代类群在不同基因树中缺少不同外围样品时，会被拆成多个小箱，低估绿色主冲突并高估其他冲突。两部分饼图使用一致／总冲突，不受此次分类缺陷影响。

原始输入、定根准入、支持率阈值、一致／总冲突／无信号、分母、完整样品云层筛选、树拓扑、枝长和定年均不改。修复只涉及四类统计中主冲突与其他冲突的划分。

## v2 契约

统计仍唯一归属 `core/phyparts-engine.js`，无 DOM、文件系统、网络、应用状态和 Java 依赖。依据 Smith et al. (2015) 的有根分支与双侧包含定义独立实现，不复制上游程序；以下候选构建策略是明确披露的 PhyloRender 行为，不承诺官方 PhyParts 缺样品结果等价。

1. 每个实际观测到的内群样品集合建立候选，合并该内群的已观测外围排除样品，不补造新内群。
2. 观测分支的内群与外围分别完全包含于候选的对应两侧时，支持该候选。部分分支可以支持多个候选；不能通过部分分支把矛盾候选合并。
3. 同一棵基因树对同一候选只计一次，主冲突取最大支持树数，其他冲突取总冲突减去主冲突。
4. 完整样品集保留精确类群计数捷径，结果与原规则相同；混合样品集按 scope 分桶后查候选投影，等价去重，无抽样、截断或修改分母。
5. 算法升级为 `phylorender-conflict-statistics-v2`，科学缓存键升级为 5。网页校验共享引擎版本，能力说明与兼容 HTTP 包装器同步。旧图 revision 保留原来源。
6. 本地可选默认快照从其原始 13797 棵研究树重算，准入仍 58；核心计数、全部树和年龄逐项保持一致。历史文件保存在忽略目录。默认入口拒绝过期自动快照，且在工作区／控件变更之前拒绝。
