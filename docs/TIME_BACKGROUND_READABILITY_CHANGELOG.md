# 时间背景可读性变更

- Dating树和基因树—物种树冲突图继续共用`render/time-background.js`。
- 最新规则取代此前的Holocene外置箭头及“其他缩写可压边框”的例外：每个年代都先按实测宽度尝试全称、短缩写和最短缩写；连最短缩写也放不下时直接省略文字，不允许跨边界或与相邻字符重叠。
- 年代色块本身不再各画一条半透明细边；每行只画一个1 px不透明外框，同一公共分界线只画一次，并使用适合水平／垂直线的清晰边缘渲染。
- Oligocene新增可辨认的最短形式`Olig`；对于物理上连`Q`、`Pl`、`Ps`或`H`都放不下的色块，仍保留真实颜色与时间边界，但不强行画字。
- 补齐此前遗漏的Early Cretaceous（145–100.5 Mya）世级色块；宽度足够时显示`Early Cretaceous`，较窄时显示`Early K`。150–145 Mya不属于白垩纪，仍按真实边界保留在白垩纪色块之外。
- 不再为Holocene或其他年代绘制箭头、外置名称或额外图例。
- 图中只保留色块内的全称或缩写，不再在右侧重复绘制“缩写 = 全称”列表；缩写全称应写入论文图注。
- 年代、世、坐标刻度和时间单位的默认字号分别为16.5、14.25、15.75和15 pt，均为旧默认值的2倍。
- Dating树和云树不再绘制图底说明行，也不再为其保留画布空白。节点年龄来源、标签范围、HPD含义、时间单位和校准来源继续保留在配置与MCP报告中，交由论文图注说明。
- `legend_size_pt`和`key_size_pt`仅为旧配置兼容字段，不再对应可见控件或图内文字。
- 用户显式指定的字号继续优先；年代边界、配色、树、年龄、HPD、拓扑和样品名称不改变。

2026-11-03补充：Dating／云树的背景填色连续延伸到底部年代条上沿，不再留下白缝；仅背景高度改变，年代条、树与时间轴位置不变。详见 `GEOLOGICAL_BACKGROUND_GAP_CHANGELOG.md`。


2026-11-06更新：本记录中的145 Ma旧边界由固定ICS 2026/06数据表替代，白垩纪起点现为143.1 Ma；背景已连续覆盖0–4567 Ma。文字适配与单次框线规则继续沿用，详见GEOLOGIC_TIMESCALE_CHANGELOG.md。

2026-11-23更新：用户确认较窄的可见地质年代色块（如100 Ma尺幅下的Quaternary `Q`、Pliocene `Pl`、Pleistocene `Ps`）不应留白。`render/time-background.js`继续优先按正常字号尝试全称→短缩写→最短缩写（原本放得下的格子字号与排版保持不变）；仅当默认字号连最短缩写也放不下时，单独将该格子的最短缩写按色块可用净宽等比缩小（行内`font-size`，标记`data-label-shrunk="true"`）以完整落入格内，绝不跨界或压边框；仅当缩小后低于`4 px`可读下限的微观线缝（如100 Ma下的Holocene）才省略文字。Dating树与云图共用同一实现。
