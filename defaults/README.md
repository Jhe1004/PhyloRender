# 演示数据来源与边界

普通树演示沿用获得所有者公开分发同意的研究示例。Dating 默认使用 `dating-synthetic.js`：27 个虚构样品，平衡树形、年龄和区间均为人工构造，仅用于演示绘图。所标 Ma 和区间不是估计年代或后验不确定性。

历史 `dating-workspace.js` 是从 99 样品 StarBEAST3 树提取的完整 27 样品类群。它原样保留，但存在约 2.5e-14 的非零末端年龄；当前不支持这类输入，不能静默归零，因此不再自动加载。原始名称、拓扑、数值和散列未修改。用户如需绘制该研究结果，应先在原分析流程中确认适用模型和时间来源；演示程序不会代为修正。

`cloud-workspace.local.js` 是排除公开分发的本地历史快照。缺少该文件时云树默认留空等待导入。AMD 新取回的研究树不属于这些公开示例。公开许可记录见 `docs/DEMO_DATA_PERMISSION.md`。

普通示例的调用配置明确声明主树按probability、附加支持树按percent显示，沿用示例既定单位；不从数值猜测，不修改原树文件，也不替用户确认其他输入的单位。

本地云树快照的自动统计必须与当前引擎算法版本相同；过期时在改变工作区之前明确拒绝，需从原始基因树重算，不把历史计数标成新版本。v2 规则及本地重算证据见 `docs/PARTIAL_CONFLICT_GROUPING_CHANGELOG.md`。
