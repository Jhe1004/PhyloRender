# PhyloRender Algorithmic Formulations & System Architecture

[← Back to Repository Home](../README.md) · **English** | [简体中文](ALGORITHMS_AND_ARCHITECTURE.zh-CN.md) · [User Manual & Parameter Reference](USER_MANUAL.md) · [Quick Walkthrough](USER_GUIDE.md)

This document details the mathematical formulations, layout geometry, built-in JavaScript phylogenetic conflict and penalized-likelihood branch-scaling solvers, and runtime consistency architecture underlying **PhyloRender**. For step-by-step workflows and a complete table of configurable options across the Web Workbench, MCP server, and Agent Skill, see [USER_MANUAL.md](USER_MANUAL.md).

## 1. Tree Parsing, Taxon Identity Decoupling, and Unrooted Branch Matching

### Safe Newick and Nexus parsing
PhyloRender parses standard Newick and Nexus tree files through a deterministic single-pass tokenizer that preserves raw leaf identifiers, branch lengths (rejecting negative or non-numeric values rather than zeroing them silently), internal node labels, and square-bracketed metadata comments (`[&...]`) such as Bayesian divergence times and 95% highest posterior density (HPD) intervals. For Nexus inputs, single- and double-quoted strings and nested square-bracket comment depth are tracked simultaneously while reading strictly within the boundaries of the `TREES` block; consequently, numbers or text inside annotation blocks or other Nexus blocks are never mistaken for `TRANSLATE` taxon mappings. Multi-tree Nexus files or concatenated multi-tree Newick inputs supplied to single-tree workspaces are rejected with an explicit blocking error instructing the user or caller to select or summarize a single consensus or maximum clade credibility (MCC) tree externally rather than defaulting silently to the first posterior sample.

### Decoupling raw taxon identities from formatted display names
Across all workspaces, every terminal node retains two separate representations: an immutable raw taxon identifier extracted directly from the input tree file and a display label used solely for canvas rendering. Cross-tree taxon matching, outgroup rooting, most recent common ancestor (MRCA) clade definitions, and topology verification always operate on the raw identifiers. When constructing default display labels, PhyloRender splits each raw label immediately before the first token containing digits (corresponding to a specimen voucher or sequence accession code): underscores in the leading taxonomic name prefix are converted to spaces, whereas trailing specimen or accession tokens containing internal underscores (such as `2023080906_1` or `SRR21412921`) are kept upright and unmodified. When automatic taxonomic name formatting is active, Latin genus names and infrageneric, specific, and infraspecific epithets are italicized, while taxonomic rank, open-nomenclature identification, and hybrid qualifiers (`subsp.`, `ssp.`, `var.`, `subvar.`, `f.`, `forma`, `sp.`, `cf.`, `aff.`, `sect.`, `ser.`, and hybrid `×`) are kept upright; when rank standardization is enabled (on by default), variant rank spellings such as `ssp.`/`subspecies`, `forma`/`fo.`, and `variety` are normalized in roman type to `subsp.`, `f.`, and `var.`, respectively. Custom display-name mapping tables (CSV, TSV, TXT, or `.xlsx` files) validate that every source key resolves uniquely to an existing tip on the active tree without conflicting duplicate rows (multiple distinct voucher accessions of the same species may share an identical publication display name while retaining distinct underlying identities). Conversely, during cross-tree taxon alignment and bipartition matching, strict one-to-one identity correspondence is enforced: if two distinct tips in a tree collide onto the same normalized matching key, the import is rejected immediately with an explicit ambiguity error.

### Unrooted branch split matching across inference methods
In the Phylogram workspace, a primary tree can be paired with up to 20 auxiliary support trees inferred by different methods (for example, pairing a concatenated maximum-likelihood tree with an ASTRAL coalescent species tree, Zhang et al., 2018, or a Bayesian consensus tree). Because different inference programs often output unrooted trees or root trees on different outgroup edges, matching internal nodes by rooted descendant sets can fail to pair identical branches. PhyloRender instead evaluates each tree over its normalized tip set $\mathcal{T}$ (aligning unique `out_` or `outgroup_` prefix variants automatically across trees) and indexes internal branches by their canonical unrooted taxon splits (bipartitions). Removing any internal branch $e$ partitions the tree's $N$ tips into two complementary non-empty subsets, $A_e$ and $B_e = \mathcal{T} \setminus A_e$, where trivial terminal splits with $|A_e| < 2$ or $|B_e| < 2$ are ignored. PhyloRender represents branch $e$ by the smaller subset (or by the lexicographically earlier sorted subset when $|A_e| = |B_e|$). For trees inferred over the same taxon set $\mathcal{T}$, this canonical split key is invariant to root placement, so identical evolutionary branches pair automatically regardless of how each input tree was rooted.

### Support-scale verification and full-support classification
Branch support values are validated independently for each slash-delimited column of each source tree before rendering. In automatic scale-detection mode, a column is classified as percentage supports ($[0, 100]$) only when it contains values $> 1$ and contains no fractional values strictly within $(0, 1)$. Whenever a column contains any fractional value in $(0, 1)$ (even if mixed with values $> 1$) or contains only `0` and `1` without values $> 1$, PhyloRender rejects the ambiguous automatic scale and requires an explicit unit declaration (`probability` or `percent`). Low-support masking (replacing values strictly below a chosen cutoff with an en-dash `–`) and gene-tree discordance thresholds are always evaluated on raw unrounded numbers. Visual full-support styling (such as drawing subtending branches at $2.5\times$ baseline stroke width in place of repetitive `100/1.00` text) is applied only when every configured support source is present on that branch and reaches its respective maximum (`100` for percentages, `1` for probabilities) at the active display rounding precision (without rounding in raw-string `original` mode).

## 2. Score-Guided Node-Label Placement and Bridged Leader-Line Routing

### Internal design coordinate space, traversal order, and local obstacle envelope
All geometric layout and collision-avoidance calculations execute on a fixed-width internal design canvas of $1,511\text{ px}$, which is linearly scaled upon completion by $1,000 / 1,511 \approx 0.6618$ onto PhyloRender's canonical $1,000$-unit (`u`) figure width (all pixel constants in Sections 2 and 3 refer to this $1,511\text{-px}$ design space). In the Phylogram workspace, labels containing narrow masked markers (`–`) are placed before purely numeric strings (preserving tree traversal order within each group) so compact threshold markers can occupy tight slots beside their nodes before wider multi-method strings (such as `98/0.99`) are routed; in the Time Tree and Tanglegram workspaces, candidate nodes are ordered from top to bottom by vertical canvas coordinate. Around each internal node at $(x_0, y_0)$, the solver collects all branch segments, internal node markers, rendered tip-label boxes, and previously placed node labels and leader lines within a local search box extending $R = 192\text{ px}$ ($96\text{ px}$ in Tanglegram) plus the preferred label dimensions and an $8\text{-px}$ margin around $(x_0, y_0)$.

### Multi-font candidate generation across geometric corridors
Rather than fixing a single offset or shrinking text arbitrarily, the engine evaluates discrete readable font sizes $s \in \{s_{\text{pref}}, s_{\text{pref}}-1, \dots, s_{\text{min}}\}$ stepping down in $1\text{-px}$ increments from the preferred node-label size to the configured readability floor. At each candidate size $s$, the exact SVG glyph bounding box $(w, h)$ of the label string is measured on the live canvas, and three families of candidate rectangles are generated around $(x_0, y_0)$. The first family samples directional radial rings across six primary orientations (left, lower-left, upper-left, right, upper-right, and lower-right) at adjacent clearance ($4\text{ px}$), expanding radial distance bands from $8$ to $192\text{ px}$ (supplemented by cardinal vertical offsets and an orthogonal offset grid) with priority given to the ancestral side of the split. The second family samples branch-corridor slots by pairing horizontal coordinates aligned with the clearance edges ($\pm 3.05\text{ px}$) of nearby vertical branch segments and the midpoints of corridors between parallel vertical branches against the top, midpoint, bottom, and node-clamped offsets of open vertical intervals between adjacent horizontal branches (with a $3.25\text{-px}$ vertical guard). The third family samples obstacle-boundary slots immediately above or below already placed neighboring labels (with a $2.05\text{-px}$ vertical guard) across horizontal offsets from the node, followed by spatial sector sampling across distance and quadrant bands.

### Exact Liang–Barsky collision filtering
Every candidate rectangle is tested against all local obstacles before routing evaluation. Intersections between padded candidate text boxes ($3\text{-px}$ clearance around branch segments, $2\text{-px}$ around other text boxes, $1.5\text{-px}$ around existing leader lines, $\max(3, r_{\text{node}}) + 1\text{ px}$ around foreign internal nodes, and $4\text{-px}$ canvas margin clearance) and horizontal, vertical, or diagonal line segments are computed exactly using the parametric Liang–Barsky line-clipping algorithm rather than coarse bounding-box approximations. Any candidate colliding with a branch, tip label, placed node label, leader line, or foreign node is rejected immediately.

### Joint typography and leader-routing cost function and multi-pass global refinement
For each collision-free candidate rectangle $\mathbf{r}$ at font size $s$, PhyloRender evaluates straight dashed leader-line connections from $(x_0, y_0)$ to central attachment points along the nearest visible edge of the label box. Font size and leader geometry compete simultaneously under a single additive objective function:
$$C(s, \mathbf{r}) = C_{\text{font}}(s) + C_{\text{route}}(\mathbf{r}) + C_{\text{pos}}(\mathbf{r})$$
The typography penalty $C_{\text{font}}(s)$ increases quadratically as the font size steps down from $s_{\text{pref}}$ toward $s_{\text{min}}$:
$$C_{\text{font}}(s) = 20\,u_s + 25\,u_s^2, \quad u_s = \frac{\max(0,\, 1 - s / s_{\text{pref}})}{0.05}$$
When node-arrow leader lines are enabled, $C_{\text{pos}}(\mathbf{r}) = 0$ in the Phylogram and Time Tree workspaces (in Tanglegram, inward-facing placements add a side penalty of $18$; when leader lines are disabled, $C_{\text{pos}}$ penalizes non-adjacent drift), and any leader path that intersects another text box is disallowed ($C_{\text{route}} = \infty$). For legal leader paths, the routing cost combines topological crossings, length, and angular deviation:
$$C_{\text{route}}(\mathbf{r}) = 2800\,n_{\text{node}} + 650\,n_{\text{leader}} + 180\,n_{\text{branch}} + 10\,u_L + 10\,u_L^2 + 300\,\max(0, u_L - 2)^2 + 6\left(\frac{|\theta - 45^\circ|}{15^\circ}\right)^2 + 100\,E(\theta, L)$$
where $L$ is the leader length in design pixels, $u_L = L / L_{\min}$ with minimum target leader length $L_{\min} = 14\text{ px}$, $\theta \in [0^\circ, 90^\circ]$ is the leader angle relative to the horizontal axis (targeting an ideal $45^\circ$ diagonal within a preferred $20^\circ\text{--}80^\circ$ window), $E(\theta, L) = \max(0, 19.75^\circ - \theta) + \max(0, \theta - 80.25^\circ) + \max(0, 13.9 - L)$ penalizes out-of-window angles and sub-minimum pointer lengths (within tolerances of $0.25^\circ$ and $0.1\text{ px}$), and $n_{\text{branch}}$, $n_{\text{leader}}$, and $n_{\text{node}}$ count crossings over branch lines, existing leader lines, and foreign node clearances, respectively. The solver selects $(s^*, \mathbf{r}^*)$ minimizing $C(s, \mathbf{r})$ and breaks ties within $10^{-6}$ in favor of larger font sizes. Following initial placement and live `getBBox` verification, Phylogram and Time Tree layouts run multi-pass global ink-box refinement passes (iterative collision repair, single-label and pairwise discrete slot swaps, font-size recovery, and crossed-leader quadrant uncrossing). Whenever a leader line crosses a branch segment ($n_{\text{branch}} > 0$), a white halo underlay ($3.8\text{ px}$ stroke width at $0.97$ opacity) is rendered beneath the $1.15\text{-px}$ dashed pointer above the branch layer to create a clean white visual gap ("bridge") at every branch crossing.

## 3. Hierarchical Clade Brackets, ICS Geologic Timescale Adaptation, Aspect Balancing, and Two-Panel Splitting

### Multi-tier clade hierarchy and collinear vertical alignment
Taxonomic or phylogenetic highlights are defined semantically by one or more raw tip identifiers (a single tip highlights an individual terminal lineage, whereas two or more tips define the clade subtended by their MRCA). PhyloRender sorts defined groups by ascending tip count and derives their nesting hierarchy automatically by strict subset inclusion of descendant tip sets: an inner clade (tier $t = 0$) colors its descendant branches and tip names, while enclosing outer clades occupy outer tiers ($t = 1, 2, \dots$). In automatic line-style mode, tier $t = 0$ uses solid brackets, tier $t = 1$ uses cap-locked evenly spaced dashed brackets, and higher outer tiers ($t \ge 2$) use dash-dot brackets with solid horizontal end-caps. Explicit tier indices ($t \in \{0, \dots, 5\}$) are also supported so a monotypic subfamily and its sole tribe can occupy distinct nested tiers on the exact same node. Clade title font sizes default to $3\text{ u}$ larger than the active tip-label font size. Whenever two or more tiers are present (or whenever tips are flush-aligned, as in chronograms and cloudograms), all brackets in tier $t$ are locked onto a shared horizontal coordinate $X_t$ to form strictly aligned vertical columns; if two vertical titles in the same tier come within $8\text{ px}$ vertically, only the colliding text is shifted rightward into an adjacent lane in steps of $\text{round}(1.35\, s_{\text{clade}})$ while the bracket bars remain collinear on $X_t$.

### Official ICS geologic timescale and adaptive narrow-cell fitting
The Time Tree and Cloudogram workspaces share a single geologic background and axis renderer backed by the official International Commission on Stratigraphy (ICS `2026/06`) chronostratigraphic chart spanning $0\text{--}4567\text{ Ma}$ (Cohen et al., 2013), including formal Precambrian eras and periods. For each visible interval $[t_{\text{young}}, t_{\text{old}}]$ of pixel width $W_{\text{cell}}$, the label fitter tests in order whether the full interval name (e.g., `Pleistocene`), standard short abbreviation (`Pst.`), or shortest abbreviation (`Ps`) fits at the default period or epoch font size $s_0$ with internal horizontal padding. When a narrow interval near the present (such as Quaternary `Q`, Pliocene `Pl`, or Pleistocene `Ps` on a $100\text{ Ma}$ axis) cannot accommodate even its shortest abbreviation at $s_0$, PhyloRender scales only that cell's shortest abbreviation down to $s_{\text{fit}} = \min\bigl(s_0,\, s_0 \cdot W_{\text{avail}} / W_{\text{natural}}\bigr)$ (where $W_{\text{avail}} = W_{\text{cell}} - \min(4, \max(2, 0.18\,W_{\text{cell}}))$, stepping down in $0.25\text{-px}$ increments until the measured glyph width fits inside the cell). Microscopic intervals whose available width is non-positive or whose fitted abbreviation would fall below the $4\text{-px}$ readability floor retain their colored stratigraphic band and hover metadata but omit printed text so labels never spill across borders or require external arrows.

### Median-based tip-width compression and portrait row expansion
To prevent a few unusually long taxon or voucher strings from compressing the horizontal tree span, PhyloRender measures the natural glyph widths $\{w_1, \dots, w_N\}$ of all displayed tip labels and computes their median $W_{\text{med}}$. Only outlier labels exceeding $1.25\,W_{\text{med}}$ are compressed horizontally (via SVG `textLength` with `spacingAndGlyphs`) to cap their width at $1.25\,W_{\text{med}}$; shorter names remain at natural proportions without character truncation or changes in font height. Vertically, in the Phylogram, Time Tree, and Cloudogram workspaces, automatic portrait balancing expands row spacing on sparse trees ($N \le 80$) toward a target height-to-width aspect ratio of $1.25$, bounded above by $\min(3\text{ em},\, 72\text{ px})$ ($\approx 47.65\text{ u}$). Across $80 < N < 120$ tips, the extra row expansion blends smoothly back to the compact baseline spacing via the cubic Hermite weight $w(p) = 1 - 3p^2 + 2p^3$, where $p = \text{clamp}\bigl((N - 80)/40,\, 0,\, 1\bigr)$.

### Automated monophyletic two-panel splitting
For tall phylograms and chronograms exceeding the single-panel capacity ($N > 76$ tips), two-panel export splits the tree once after outgroup rooting and ladderization. All tips in the rooted outgroup are marked as protected so the root and outgroup remain in Panel 1. Among non-root internal nodes containing no outgroup tips, the splitter identifies candidate monophyletic clades of size $K$ that leave at least $N_{\min} = \max\bigl(2,\, \min(38, \lceil 0.25 N \rceil)\bigr)$ overview tips in Panel 1. Candidates satisfying $K \ge N - 75$ (which bring Panel 1, including one continuation guide row, within the $76$-row capacity) are ranked by bottom-most terminal index, breaking ties among nested clades sharing the bottom tip in favor of the smallest sufficient clade $K$ so Panel 1 retains maximal overview context. Panel 1 replaces the extracted subtree with a continuation guide row indicating the continued $K$-tip clade in Panel 2 (preserving the stem branch length on phylograms, or extending to the present $0\text{ Ma}$ line on chronograms), while Panel 2 renders the complete $K$-tip monophyletic clade at the identical $1,000\text{-u}$ canvas width and font scale and inherits any spanning outer clade bracket automatically.

## 4. Tanglegram Sister-Clade Untangling Algorithm

### One-to-one taxon audit and degree-2 branch-length preservation
In the Tanglegram workspace, two trees $T_1$ (left, primary reference) and $T_2$ (right, comparison) are matched one to one by normalized raw tip identities (trimmed of outer quotes, collapsed across whitespace/underscore runs, and case-folded, rejecting intra-tree duplicate collisions). If the two tip sets $\mathcal{L}(T_1)$ and $\mathcal{L}(T_2)$ are not identical, equal-count name mismatches prompt source-name verification first, while differing taxon sets require an explicit retention policy: `intersection` prunes both trees to $\mathcal{L}(T_1) \cap \mathcal{L}(T_2)$ while summing serial branch lengths across collapsed non-root degree-2 internal nodes so pairwise patristic distances remain exact, whereas `union` retains all tips from both trees and draws connectors exclusively across shared taxa.

### Single-pass median-rank sister-clade untangling on the comparison tree
To preserve the user's chosen reference ordering, PhyloRender keeps the vertical clade order of the left primary tree $T_1$ fixed (as determined by its ladderization setting or manual sister-clade swaps) and rotates sister clades on the right comparison tree $T_2$ only. Each retained tip $t$ in $T_1$ occupies a fixed vertical row index $r_1(t) \in \{0, 1, \dots, |\mathcal{L}(T_1)| - 1\}$. Traversing $T_2$ bottom-up in postorder, each child subtree $c_i$ of an internal node $u$ is assigned the median row index in $T_1$ of its shared descendant tips:
$$m(c_i) = \text{median}\bigl\{\, r_1(t) \;\big|\; t \in \mathcal{L}(c_i) \cap \mathcal{L}_{\text{shared}} \,\bigr\}$$
(with $m(c_i) = +\infty$ under `union` if $c_i$ contains no shared tips, placing unmatched subtrees after shared siblings while preserving their relative input order). Sorting the children of every internal node $u$ in $T_2$ by ascending $m(c_i)$ (preserving original order on ties) yields a candidate topology-preserving orientation of $T_2$, which is accepted if and only if it does not increase the shared-taxon connector inversion count relative to the unmodified orientation:
$$K = \sum_{1 \le i < j \le M} \mathbb{I}\bigl(r_2(\pi_i) > r_2(\pi_j)\bigr)$$
where $(\pi_1, \dots, \pi_M)$ is the top-to-bottom sequence of shared taxa in $T_1$ and $r_2(\pi_i)$ is the vertical rank of $\pi_i$ in $T_2$. Shared tips are joined across the central corridor of net width $W = \text{right} - \text{left}$ between the two tip-label columns by horizontal-entry cubic Bézier curves (`M x1 y1 L left y1 C left+0.36W y1, right-0.36W y2, right y2 L x2 y2`) so connectors never cross label text.

## 5. Built-in Gene-Tree Discordance, Penalized-Likelihood Visual Alignment, and Cloudogram Rendering

### Gene-tree outgroup rooting and order-invariant four-category discordance counting
In the Cloudogram workspace, a rooted species tree $T_S$ (taxon set $\mathcal{S}$, up to $1,000$ taxa) is analyzed alongside a batch of gene trees $\{G_1, \dots, G_M\}$ (up to $20,000$ trees per run). Under the default outgroup-rooting policy, using the tip set $\mathcal{O}_{\text{root}}$ of one root child of $T_S$, each gene tree $G_k$ is rooted automatically on the separating edge of its observed outgroup subset $\mathcal{O}_{\text{root}} \cap \mathcal{L}(G_k)$ whenever that subset is non-empty, leaves at least two ingroup taxa, and forms a single monophyletic split in the unrooted gene tree; non-conforming gene trees are logged individually in the audit report and excluded without discarding the remaining collection.

Following Smith et al. (2015), every internal node $v$ of $T_S$ defines a rooted ingroup clade $I_v \subset \mathcal{S}$ and an outside taxon set $O_v = \mathcal{S} \setminus I_v$. For each comparable rooted gene tree $G_k$ with observed taxon set $S_k \subseteq \mathcal{S}$ (encoded as arbitrary-precision `BigInt` bitmasks), let $I_{v,k} = I_v \cap S_k$ and $O_{v,k} = O_v \cap S_k$ denote the projection of node $v$ onto $S_k$. Given a support cutoff $\tau \in [0, 0.999]$, let $\mathcal{C}(G_k, \tau)$ denote all non-trivial internal clades of $G_k$ when $\tau = 0$ (no support filter, retaining unannotated clades as well), or all internal clades carrying a numeric support strictly exceeding $\tau$ when $\tau > 0$. At species-tree node $v$, gene tree $G_k$ is **uninformative** if $|I_{v,k}| < 2$ or $|O_{v,k}| < 1$, or if no clade in $\mathcal{C}(G_k, \tau)$ either matches or conflicts with $I_{v,k}$. When missing taxa in $G_k$ cause multiple nested ancestor nodes of $T_S$ to project onto the exact same subset $I_{v,k}$, ownership of $I_{v,k}$ is assigned uniquely to the most specific (smallest-$|I_v|$) species-tree node: $G_k$ is counted as **concordant** at $v$ if $I_{v,k} \in \mathcal{C}(G_k, \tau)$ and $v$ is that unique most-specific owner (preventing missing data from inflating concordance on deeper backbone nodes, which are recorded as uninformative). Conversely, $G_k$ is counted as **conflicting** at $v$ if $\mathcal{C}(G_k, \tau)$ contains one or more clades $C \subset S_k$ topologically incompatible with $I_{v,k}$ ($C \cap I_{v,k} \ne \emptyset$, $I_{v,k} \setminus C \ne \emptyset$, and $C \cap O_{v,k} \ne \emptyset$).

When all gene trees have complete taxon sampling ($S_k = \mathcal{S}$), conflicting clades group by exact bitmask equality, separating the **dominant alternative** from **remaining alternatives**. When some gene trees lack taxa ($S_k \subset \mathcal{S}$), sequential greedy binning would depend on gene-tree input order. PhyloRender eliminates order dependence by pairing each observed conflicting clade with its observed tree scope $(C, S_k)$ and forming candidate clades $(C^*, S^*)$ where $S^* = \bigcup_{(C^*, S_j)} S_j$ is the union of scopes across trees directly observing $C^*$. A partial conflicting split $(C, S_k)$ contributes to $(C^*, S^*)$ if and only if $S_k \subseteq S^*$, $C = C^* \cap S_k$, and $(S_k \setminus C) \subseteq (S^* \setminus C^*)$, with each conflicting gene tree contributing at most one count to any candidate. Taking the maximum pooled count $n_{\text{dom}}(v)$ across candidates and setting $n_{\text{other}}(v) = n_{\text{conflict}}(v) - n_{\text{dom}}(v)$ guarantees strict invariance to gene-tree input order.

### Penalized-likelihood ultrametric visual alignment
To overlay gene trees visually onto the time axis of $T_S$, PhyloRender selects comparable gene trees containing the complete species set ($\mathcal{L}(G_k) = \mathcal{S}$) and valid ML substitution branch lengths (excluding degenerate trees with $\ge 80\%$ zero-length terminal branches, bounded at $30,000$ total overlay nodes without subsampling) and scales each tree to shared species-tree clade ages (an undated ML species tree can also be calibrated to a user-supplied root age by the same solver). Following Sanderson (2002) and Smith & O'Meara (2012), each non-root branch $i \in \{1, \dots, |E|\}$ with parent $p(i)$ and ML branch length $b_i \ge 0$ is mapped to an effective character count $c_i = \text{round}\bigl(\max(b_i, 1/N_{\text{sites}}) \cdot N_{\text{sites}}\bigr)$ with $N_{\text{sites}} = 10^8$ and smoothing weight $\lambda = 100$. Terminal nodes have $t_i = 0$, the root has $t_0 = T_{\text{root}}$, and every internal gene-tree node matching a species-tree clade has fixed age $t_i = t_i^{\text{fixed}}$. The rate-smoothed Poisson penalized-likelihood objective is:
$$\mathcal{J}(\mathbf{r}, \mathbf{t}) = \frac{1}{N_{\text{sites}}} \left[ \sum_{i=1}^{|E|} \bigl(r_i d_i - c_i \ln(r_i d_i)\bigr) + \lambda \sum_{p(i) \ne 0} (r_i - r_{p(i)})^2 + \frac{\lambda}{k_0} \sum_{j \in \text{children}(0)} (r_j - \bar{r}_0)^2 \right]$$
where $r_i > 0$ is the branch rate, $d_i = t_{p(i)} - t_i > 0$ is the branch duration, $k_0$ is the root degree, and $\bar{r}_0 = \frac{1}{k_0}\sum_{j \in \text{children}(0)} r_j$.

To minimize $\mathcal{J}$ without external C++ `ADOL-C` or `NLopt` dependencies, PhyloRender maps the constrained variables onto an unconstrained vector $\mathbf{x} \in \mathbb{R}^{1 + |E| + |V_{\text{free}}|}$. Branch rates are parameterized in log space as $r_i = \exp\bigl(\text{clamp}(x_0 + \alpha\, x_i,\, -45, 45)\bigr)$, with scale factor $\alpha$ normalized from total effective substitutions and initial total branch duration. For each free internal node $u \in V_{\text{free}}$, a bottom-up pass computes its oldest fixed descendant bound $L_u = \max\bigl(\{0\} \cup \{\, t_w^{\text{fixed}} \mid w \in \text{desc}(u) \,\}\bigr)$, and a top-down pass expresses $t_u$ as a logistic interpolation between its parent age $t_{p(u)}$ and $L_u$:
$$t_u = L_u + \sigma(z_u)\bigl(t_{p(u)} - L_u\bigr), \quad \sigma(z_u) = \frac{1}{1 + e^{-z_u}}, \quad z_u \in [-32, 32]$$
Keeping $0 < \sigma(z_u) < 1$ strictly in double-precision arithmetic guarantees positive branch durations $d_i > 0$ even across zero-length or micro-length radiation edges. Exact $\mathcal{O}(|V|)$ analytical gradients are obtained via postorder backpropagation:
$$\frac{\partial \mathcal{J}}{\partial z_u} = \frac{\partial \mathcal{J}}{\partial t_u}\bigl(t_{p(u)} - L_u\bigr)\sigma(z_u)\bigl(1 - \sigma(z_u)\bigr), \quad \frac{\partial \mathcal{J}}{\partial t_{p(u)}} \leftarrow \frac{\partial \mathcal{J}}{\partial t_{p(u)}} + \frac{\partial \mathcal{J}}{\partial t_u}\sigma(z_u)$$
and minimized by a built-in deterministic L-BFGS solver (history size $m = 16$, two-loop recursion with Barzilai–Borwein Hessian scaling, regular Wolfe line search with $c_1 = 10^{-4}$ and $c_2 = 0.9$, and gradient infinity-norm tolerance $10^{-11}$).

### Cloudogram row anchoring, species-tree MRCA coloring, and deterministic jitter
During cloudogram layout, every gene-tree internal node whose descendant taxon set matches a clade of $T_S$ is anchored to that species-tree node's exact vertical coordinate ($Y$); gene-specific discordance nodes initialize at the mean $Y$ of their children and, when spanning $\ge 3$ rows, undergo two local refinement sweeps across quantile offsets to minimize branch crossings and close-approach crowding before settling near the child midpoint. Each gene branch is colored in $\mathcal{O}(\log N)$ time via a binary-lifting lowest common ancestor table on $T_S$, inheriting the group color of its descendant tips' species-tree MRCA (uncolored backbone ancestors remain neutral gray). When optional branch jitter ($\text{strength} \in \{1, \dots, 100\}$, default $0$) is enabled, non-zero-span gene branches are drawn as cubic Bézier curves with control points $(x_p + \Delta x/3,\, y_p + \Delta y/3 + \delta_y)$ and $(x_p + 2\Delta x/3,\, y_p + 2\Delta y/3 + \delta_y)$, where $\delta_y$ is derived via a deterministic 32-bit FNV-1a hash of the root, parent, and child topological clade signatures and tree index such that the mid-curve peak deflection reaches up to $0.5$ row heights at strength $100$ (corresponding to $|\delta_y| \le \frac{2}{3}$ row heights, clamped to the plot bounds) while keeping all node endpoints and time coordinates fixed.

## 6. Shared Headless Runtime, Optimistic Concurrency Control, and Transactional State Consistency

### Single-engine equivalence across browser and programmatic execution
To guarantee identical geometry, font metrics, and data validation across interactive and automated sessions, PhyloRender avoids maintaining separate plotting implementations for the web interface and the Model Context Protocol (MCP; Anthropic, 2024) server. Instead, the MCP server hosts the exact same modular JavaScript parsing, scientific preparation, collaborative render-scheduling, and SVG/PNG serialization code inside a managed headless Chromium runtime on the shared $1,000\text{-u}$ figure contract. Batch gene-tree parsing, discordance counting, and penalized-likelihood alignment execute inside dedicated Web Workers that are terminated immediately upon cancellation, timeout, or page exit, while bounded server job queues and process-group supervision govern auxiliary local services and optional native helpers so aborted tasks leave no orphaned background processes.

### Immutable revision history, optimistic concurrency, and atomic rollback
Every figure managed by the server maintains an append-only chain of immutable revisions (`revision 1, 2, ...`), storing its validated specification, SHA-256 hashes of all raw tree and table inputs, layout collision diagnostics, and topology fingerprints. Programmatic modification calls must supply the caller's known `base_revision` inside a per-figure serial queue; stale `base_revision` values are rejected immediately with a structured `REVISION_CONFLICT` error rather than overwriting concurrent updates. Across both interfaces, full specification imports and multi-operation edits execute atomically: the browser runtime captures a complete document, control, and cache snapshot prior to execution and restores it cleanly if any validation or rendering step fails, while the MCP store stages renders inside temporary directories and commits new revisions via atomic directory rename only after all checks succeed.
