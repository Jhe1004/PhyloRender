# 98阶段：样品名称粗体控件归位

从97号已验收源码建立独立副本。将原来的`tip-font-bold`控件及其整行，从“学名格式”移到“名称字体与颜色”的字号设置之后。普通树、Dating树、基因树—物种树冲突图和双树冲突对照继续共用同一个控件。

“名称字体与颜色”说明调整为“字体、字号、粗体与颜色”；“学名格式”说明改为“斜体与分类等级缩写”。粗体属于字体外观，斜体识别与分类等级缩写仍在学名格式中。

没有新增ID或复制开关，没有修改默认勾选状态、事件监听器、字号、MCP字段`options.typography.tips.bold`、配置导入导出、样品身份、科学计算或渲染算法。app.js、agent-bridge.js、CSS、名称模块及其他生产代码不修改。

原样品名称专项增加工作台位置检查：只展开字体面板、保持学名格式收起时，粗体必须可见并可用。四种模式实际勾选与取消，检查样品文字700／400字体权重、源树／统计保持、配置和同源渲染。测试仍走真实DOM事件和原渲染路径；旧位置的红色反例保留。

本阶段依照项目规范执行基础检查、完整集成及21组新旧SVG／完整PNG精确对照。SVG只排除metadata，不放宽其他属性、字体、坐标、图层顺序或像素。实际通过以本阶段verification.json和命令退出码为准。

此次只整理控件位置，不是整个软件全功能／跨平台验收。未部署、推送、重启共享服务、构建Docker／安装包或批准许可；88号历史PNG差异根因仍保留。
