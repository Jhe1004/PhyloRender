# 110阶段：MCP默认样品名称可读性

2026-11-11后续变更：下述字形间隙规则保留为最小行距基线；最终自动行距改由整图高宽目标和稀疏/密集策略共同决定，见[AUTOMATIC_PORTRAIT_LAYOUT_CHANGELOG.md](AUTOMATIC_PORTRAIT_LAYOUT_CHANGELOG.md)。默认字号和科学输入保护不变。

## 需求

MCP直接生成图件时，末端样品名称必须默认看得清楚。密集树不能依靠缩小文字换取整齐；相邻名称之间也不能留下无意义的大空白。稀疏树可以保留较宽松的空隙。

## 规则

- 普通树与双树冲突图默认样品名称为15 pt。
- Dating树与基因树—物种树冲突图默认样品名称为18 pt。
- 四种工作区默认启用自动样品间距。
- 12个及以下样品最多保留0.3 em可见字形间隙；12至48个样品平滑收紧；48个及以上约留1绘图px。
- 自动间距使用实际字体、斜体片段和当前显示名称的测量高度，不把字号当作字形高度。
- 节点标注通过移动自身和引导线避让，不得增加样品行距。
- 用户显式给出的字号或手动间距继续优先，切换工作区时分别保存。

## 实现边界

默认字号、密度阈值和目标间隙只在`figure-contract.js`定义。`app.js`负责浏览器字形测量并调用该规则；`agent-bridge.js`、MCP store、schema和agent说明只传递或说明同一配置，不另建算法。树拓扑、顺序、枝长、支持率、年龄、HPD和PhyParts统计均不改变。

## 验收重点

1. 默认配置在四工作区、网页和MCP中一致。
2. 密集和稀疏树直接测量相邻文字的真实可见间隙。
3. 显式字号和手动间距往返无损。
4. 普通树、Dating树、云树和双树冲突图的科学输入与输出字段保持不变。
5. 大树、取消和后台清理继续通过既有稳定性门禁。
