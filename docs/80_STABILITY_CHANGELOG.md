# 80阶段：大数据稳定性与后台任务回收

基于78阶段审计整改源码，未改动历史78/79、原始数据、treePL/PhyParts科学参数或许可证决定。

## 本轮修改

- 抽出共享Newick/Nexus/注释解析器及基因树批次科学准备，移至独立Worker，网页与MCP调用同一路径。
- 单树绘图和整批云层设明确准入预算；不剪树/不抽样统计，不把云层超限当完整图导出。
- 导入增加取消按钮、600秒事务总时限、Worker120秒时限和失败回滚；普通/Dating/云层导入协作渲染。
- 真实完整云层压力测试揭示同步交叉优化阻塞；保留原评分和候选顺序，增加协作执行与精确几何缓存，设置调整也使用协作路径。冻结78阶段几何结果作为回归反例。
- 大量饼图的候选位置搜索也逐候选让出执行权；原坐标、半径和顺序精确回归，增加取消不修改输入的反例。
- 双树支持率标签仍同步穷举的遗漏已补上：导入、交互重绘和MCP最终呈现均走协作渲染；增加两棵各1500末端树排版中取消并保留主树的浏览器反例。
- 导出入口等待设置与异步排版真正完成；字体过期时使用协作重绘，计算进行中或设置排版失败时明确拒绝不完整SVG。网页/MCP严格SVG一致性测试等待任务终态，仍比较全部字体、坐标与图层。
- 再次检查旧交互入口，饼图、分组、样品名称、字体回调等旧renderTree/renderCloudTree调用统一改为可取消协作事务；MCP报告和A4逐页/恢复也await协作重绘。云图根年龄重算纳入同一事务，保留科学约束不变。
- 原先假定同步重绘的浏览器回归改为await重绘、等候真实任务终态并flush设置；所有坐标、字体、顺序和科学数据断言保留。无树的云图空画布没有昂贵排版，不占用导入事务，避免输入类型选择与随后的文件上传相撞。
- 最终原生专项还发现物种树导入的外层catch重复回滚、再次启动重绘，覆盖了真正的导入错误提示。已删除这层重复事务，由runTreeLoad独占回滚和终态；新增失败反例验证不再启动第二次重绘或覆盖其他导入的状态。原生浏览器专项在输入类型/单位重绘完成后再上传，不绕过界面忙状态。
- treePL新增带编号任务API；PhyParts、treePL、名称辅助程序共用租约状态机和独立进程监护器。
- 服务被强制结束时监护器管道EOF仍能回收组内引擎后代；主引擎正常退出后残留子进程也清理。
- 附加MCP宿主SIGKILL反例发现私有页面服务遗留；私有服务增加父进程所有权管道，断连即退出，共享APP_URL服务不受影响。强杀反例加入integration必跑门禁。
- 网页/MCP取消和deadline都请求本次原生任务停止并确认终态。无法确认时报告待回收，不能假报完成。
- 名称识别纳入物种树导入事务；新增客户端/服务端有界名称任务。
- 保留旧同步HTTP兼容路径，但新网页/MCP不再用它做长计算。
- 增加真实进程、HTTP、MCP、Worker和真实大输入回归；integration门禁纳入大数据浏览器测试。
