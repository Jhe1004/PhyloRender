# 86阶段：样品名称工作台模块化

基线为85阶段已验收源码。本轮是保留行为的结构迁移，不改科学输入、绘图默认值、算法、网页/MCP契约或运行服务；历史阶段保持只读。

## 本轮责任分离

- core/sample-name-state：原始样品身份解析、整批名称覆盖验证、merge/replace、恢复/清空、复制快照和待改名身份。身份算法仍唯一调用sample-identity，模块没有树或DOM端口。
- ui/sample-names：名称映射列表、改名对话框、CSV/TSV/XLSX读取入口、模板下载入口、名称状态文字，以及字体/斜体/颜色/等级控件的监听器。只能使用具体元素和限定回调；bind幂等、监听器实例私有且可dispose。
- app：保留旧函数名并短委托，GUI与agent-bridge仍走同一名称操作路径。继续协调字体识别、字体加载、量字、密度间距、导入事务和原生生命周期。

apply整批验证后才提交，因此一行有效、后一行身份未知时，不会应用前一行。每次操作读取当前工作区，不把旧Map缓存进新模块。普通树/Dating/双树历史上共用非云树覆盖表，云树表独立；此行为保留，不以重构名义改变用户状态语义。

主文件7,149→6,967行；门禁7,155→6,973行。新增ui目录进入浏览器顺序、构建指纹、受限HTTP静态白名单和Docker COPY。静态测试拒绝ui目录中的JSON、隐藏文件、深层JS和越界符号链接。没有构建Docker镜像。
