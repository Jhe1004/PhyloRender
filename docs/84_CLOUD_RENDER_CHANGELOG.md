# 84阶段：云树渲染与饼图模块化

本轮基线为83阶段已验收的macOS arm64源码。历史阶段只读，本机共享服务和公网部署不在本轮修改范围内。

## 责任拆分

- render/cloud-branches：三角与矩形物种树/基因树线条、显式分组颜色继承、实例私有行坐标缓存。
- render/cloud-pies：两部分/四部分饼图、透明独立图例、极小实心隐藏点、时间过滤与完整占位的协作排版。
- render/cloud-tree：时间背景、云层、物种树、样品名、分组条、饼图、图例及说明的组合渲染。
- app保留导入、定年、PhyParts统计、文档事务与回滚、菜单交互及中文状态反馈。每次呈现传入模型切片与选项快照，渲染器不取得整份state。

主文件7,946行减少至7,604行，体量上限由7,950收紧到7,610行；没有提高上限或删注释绕过门禁。新增3个模块登记浏览器加载、架构清单与构建目录。静态服务/Docker规则原已覆盖render目录；本輪未构建镜像。

## 行为与科学不变量

拓扑、长度、支持率、年龄、HPD、完整四类计数、分母、treePL/PhyParts参数、默认值和候选迭代顺序均沿用基线。继续使用原24ms协作预算与生成器取消传播。显示筛选与隐藏也保留所有节点的布局占位，不改变邻近饼图位置。
缓存键保留所有年龄/几何参数及根对象身份，且只在搜索完成后提交。取消不留下半成品缓存，不同工厂不共享缓存。

## 验证与迁移记录

新增9个直接模块接口反例/测试；原源代码位置检查迁至所属模块，语义和行为断言保留。精确对照扩为12组，覆盖四工作区及矩形物种树、两部分时间过滤/手工隐藏、仅基因云层、大背景字号、未确认单位配色。只排除SVG metadata，所有其他属性、文本、字体、图层顺序、几何与完整分辨率PNG均需一致。
机械提取脚本首次因index.html的app脚本查询参数锚点不匹配退出1；仅新阶段代码已写入。修正后把全部锚点预检移到写入前，脚本禁止覆盖已迁移app。后续新测试夹具/源位置适配问题保留在测试日志中，不作为生产算法修复宣称。
验收完成须以同阶段02_验证记录/verification.json、实际命令退出码及构建ID为准。
