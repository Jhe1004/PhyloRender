02Gene-Tree Discordance AnalysisBuilt-in JavaScript bipartition engine; no Java required
Not imported

Matches rooted bipartitions by exact descendant taxon sets on the species tree; discordance pie denominators are never restricted to the cloudogram-eligible subset.

Discordance options & node table

Listed taxa must match one complete root child of the species tree without altering species-tree rooting or ages. Gene trees may lack some outgroup taxa, provided present outgroups form a single monophyletic bipartition; non-conforming gene trees are excluded individually and reported.

No support cutoff is applied by default. When a non-zero cutoff is set, only branches strictly exceeding the threshold are treated as informative; unannotated branches are treated as uninformative. Gene trees lacking outgroups, containing duplicate taxa, or carrying unmatched names are reported separately and excluded from denominators. Two-part and four-part pies share a single full calculation.

03Divergence Time AlignmentSpecies-tree calibration & gene-tree display alignment

Preserves the input species-tree root; automatic rerooting is never applied.

Undated ML species trees are calibrated via treePL, whereas time-calibrated species trees retain their original node ages; shared gene-tree clades are then aligned to species-tree divergence ages for display without forcing discordant clades to coincide. Default schematic root ages are for visualization only and must not be cited as divergence estimates.

Gene-Tree Cloudogram LayerVisibility, stroke opacity, and branch jitter

0 keeps straight segments; higher values deterministically disperse mid-branch trajectories while keeping tips and shared internal nodes anchored. Affects visual rendering only without altering divergence times, topologies, or discordance counts.

Baseline opacity scales automatically with the number of overlaid gene trees so sparse clouds stay clear and dense clouds remain legible. Branches inherit the most nested species-tree clade color spanning their descendant taxa; uncolored or cross-clade branches remain neutral gray.
