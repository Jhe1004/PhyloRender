# 102阶段：极窄地质年代标签外置

本阶段从101号已验收源码建立独立副本。用户发现Holocene色块极窄时，强行居中的`H`会悬在右边界上，视觉上像与`Ps`粘在一起。本轮只改这一种极窄标签的呈现。

## 新规则

- 能容纳全称或缩写的色块继续在块内显示，与101号相同。
- 连最短缩写也容纳不下时，块内不再强行绘字。该色块用细引导线连到旁边已有的`缩写 = 全称`说明。
- 外置说明同时是色块的可见标签和缩写解释，不再重复画一个孤立的`H`。
- 色块的年代边界、宽度、颜色和背景范围不改；树坐标、年龄、HPD、拓扑、样品名称和统计不改。
- Dating树和基因树—物种树冲突图仍共用`render/time-background.js`，网页和MCP仍走同一渲染路径。

## 代码范围

- `render/time-background.js`：为色块记录内置／外置状态，极窄时将实际色块中心连到共用缩写说明。
- 引导线样式只写入该SVG元素，不新增全局CSS，避免未使用时间背景的普通树和双树图也产生无意义的导出差异。
- 直接模块反例、Dating真实浏览器／MCP与云树共用背景专项增加外置关联断言。

## 验收边界

必须核对每个可见色块要么有块内文字，要么有引导线连接的外置文字；不得用空字符、缩小字号或改大地质时间跨度规避问题。验收须覆盖Dating树、云树、大字号、网页／MCP一致、英文画布和科学数据不变。
