# 云树内置基因树冲突统计

## 定位与方法来源

PhyloRender 现在使用独立编写的 JavaScript 引擎 `PhyloRender-conflict-statistics`，算法版本为 `phylorender-conflict-statistics-v2`。网页和 MCP 使用同一个 `core/phyparts-engine.js`，不再运行 Java，不下载、打包或分发 PhyParts 源码与二进制。

统计定义依据 Smith et al. (2015) 公开发表的 rooted bipartition 方法：[Analysis of phylogenomic datasets reveals conflict, concordance, and gene duplications with examples from animals and plants](https://doi.org/10.1186/s12862-015-0423-0)。方法贡献属于原作者。PhyloRender 的代码是独立实现，不自称官方 PhyParts，也不把该方法声称为本项目原创。

## 输入与两个独立集合

上传一棵已定根物种树和包含全部基因树的 Newick 集合。原始输入文件不改写。

1. **统计集合**：根位可比较、样品名唯一、至少三个样品，且全部名称能在物种树中找到。缺少部分内群样品仍保留。
2. **云层集合**：统计集合中末端名称完全一致、通过 ML 替换枝长检查的子集。统计集合与云层集合不能互换分母。

默认可识别物种树根部的单叶外群。多外群须在统计选项中逐行明确填写，MCP 对应 `options.cloud.phyparts_outgroups`；这些名称须完整对应物种树现有二分根的一侧，物种树不重新定根。基因树可以缺少部分指定外群，但实际出现的全部外群必须能由一条边与其余样品分开；缺少全部外群或不满足此条件时逐棵报告并排除。也可显式确认输入基因树已使用可比较根位，此时不能同时指定外群列表。名称不匹配时不自动改名或剪树。完整规则见 [MULTIPLE_OUTGROUPS_CHANGELOG.md](MULTIPLE_OUTGROUPS_CHANGELOG.md)。

## 四类统计

- **一致**：基因树支持该物种树分支。
- **主冲突**：出现次数最多的一组兼容替代分支。
- **其他冲突**：总冲突减去主冲突。
- **无信号**：该节点不能由该基因树判断，包括缺失关键样品、未解析或被阈值排除。

v2 按实际观测到的内群样品集合建立候选替代关系，并合并该内群在不同基因树中观测到的外围排除样品。不会补造未观测的内群关系。某个基因分支的内群和外围分别完全包含于候选的内群和外围时，支持该候选；同一棵基因树对同一候选只计一次。部分样品分支可以同时支持多个候选，但不会把候选之间的矛盾关系连起来合并。主冲突取候选支持树数的最大值，其余冲突为总冲突减去这个最大值。

这是 PhyloRender 明确公开的候选构建策略，不承诺与官方 PhyParts 的缺样品分组结果完全相同。它替代 v1 的首次匹配贪心分箱：旧规则会因外围缺样品组合不同而拆散同一个替代关系，低估主冲突。算法版本和科学缓存键同时升级；旧图保留原版本来源，新分析不复用旧缓存。完整样品集合的结果不因这次修改改变。

自动分析始终计算并保存四类。两部分或四部分只是显示方式，切换时不重算。已有节点表仍可作为高级输入；缺少明细的旧表不能推造主冲突与其他冲突。

## 支持率与分母

- 默认阈值为 0，即不过滤。
- 非零阈值只保留严格大于阈值的分支；恰好等于阈值不保留，缺少支持率也不参与。
- 支持率单位先按整个集合判断，避免把百分比文件中的 `1` 当成 100%。
- 定根时支持率跟随原物理分支。
- 四类之和始终等于统计集合树数；有信息数等于一致加总冲突。越界或结果不完整时明确失败。

## 运行、取消与兼容接口

浏览器在独立 Worker 中统计，主界面不会承担大树循环。单次最多 20000 棵、总文本 120 MB、最长 300 秒。取消、超时或页面关闭会终止专属 Worker，不采用部分结果。

`/api/cloud-phyparts` 为旧客户端保留兼容入口；它通过 Node.js 包装器调用同一 JavaScript 核心，仍不需要 Java。显示参数变化不重新统计。物种树、基因树、定根、支持率字段、单位或阈值变化会使旧统计失效。

临时分析只使用内部 `T00000` 样品编号。输出按精确原始后代样品集合匹配节点，不依赖显示顺序。自动节点表可下载；SVG 的 `cloud-phyparts-provenance` metadata 保存引擎、算法版本、参数、筛选计数、输入文件名与定年状态。

## 显示交互

节点饼图的隐藏、显示、大小、透明度、时间范围和分支排列都只改变显示，不改变统计。隐藏后的编辑点和操作菜单不进入 SVG／PNG。更换物种树或新的手工统计表时清除旧隐藏状态。

“树形 → 分支排列”可选择保持文件顺序、较小姊妹群在上、较大姊妹群在上。排序由物种树决定，所有基因树末端与样品名称同步对齐；原树拓扑、枝长、节点时间和统计均不改变。
